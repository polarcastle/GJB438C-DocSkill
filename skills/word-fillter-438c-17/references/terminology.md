# 军用软件文档常用术语表（[17] 软件测试记录适用）

> 术语依据 GJB 438C-2021 及 [17] 模板正文用法整理。全文术语必须与本表保持一致；首次出现时用"中文全称（英文缩写）"格式。

## 配置管理与标识

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 计算机软件配置项 | CSCI（Computer Software Configuration Item） | 软件配置项，测试记录的基本对象；本文档"配置项测试记录"即针对 CSCI 的测试记录。 |
| 计算机软件单元 | CSU（Computer Software Unit） | CSCI 中可单独测试的最小软件元素；功能测试用例可按 CSU 或功能划分。 |
| 系统 | — | 由硬件、软件、人员等组成的整体；本文档"系统测试记录"针对系统级测试。 |
| 基线 | Baseline | 经正式评审确认的文档/产品版本，测试对象应基于受控基线版本。 |
| 文档标识号 | — | 格式示例 `TN/x-DO-DS-V{N.xx}`，见 1.1 节。 |
| 测试用例标识 | — | 项目唯一的测试用例编号，格式自定（如 STR-DR-001，STR=软件测试记录，DR=文档审查，FT=功能测试），全文与测试说明保持一致。 |

## 测试相关

| 术语 | 含义与使用场景 |
|------|----------------|
| 配置项测试 | 针对 CSCI 的测试，本文档 4.1 节记录：文档审查、功能测试、性能测试及其它单独格式记载的测试。 |
| 系统测试 | 针对完整系统的测试，本文档 4.2 节记录；按测试类型依次展开，格式同配置项测试。 |
| 文档齐套性检查 | 审查交付文档种类、数量、签署是否符合要求，4.1.1 节记录对象。 |
| 功能测试 | 验证软件功能符合需求规格说明的测试，4.1.2 节记录对象。 |
| 性能测试 | 验证量化指标（响应时间、吞吐率、容量等）的测试，含测试内容/条件、次数与结论。 |
| 测试环境 / 测评环境 | 执行测试所用的软硬件环境及其配置，本文档第 3 章说明；正文中"测评环境"与"测试环境"同义，沿用模板用词。 |
| 环境差异分析 | 对比测试环境与软件实际使用环境的差异及影响，3.1（3）节。 |
| 测试人 / 见证人 | 记录表中执行测试的人员与对测试过程进行见证的人员。 |

## 文档类型

| 术语 | 含义与使用场景 |
|------|----------------|
| 软件测试记录 | 本文档类型，记录配置项测试与系统测试的过程与结果。 |
| 软件测试计划 / 软件测试说明 | 测试记录的上游文档：测试项、用例与进度依据测试计划，用例标识与测试说明一致。 |
| 软件需求规格说明 | 功能与性能指标的出处，引用文件表中列出。 |

## 通用软件术语（按源码实际出现选用）

> 首次出现写"中文全称（英文缩写）"，此后用缩写；源码中未出现的不得收录。

| 术语 | 英文/缩写 | 规范写法与使用场景 |
|------|-----------|----------------|
| 应用程序编程接口 | API（Application Programming Interface） | 对外接口的统称，测试桩模拟对象。 |
| 软件配置管理 | SCM（Software Configuration Management） | 基线、变更控制相关活动，被测版本出处。 |

## 术语裁剪指引

- 只收录正文实际出现的术语；本文档不叙述需求与设计细节，需求工程类术语（如合格性方法、双向追踪）不适用，不得照搬 [08] SRS 词表。
- 「通用软件术语」一表按源码实际出现选用，不得为凑数整表照搬。
