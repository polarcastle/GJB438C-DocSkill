# 军用软件文档常用术语表（[14] 软件可靠性和可维护性设计适用）

> 术语依据 GJB 438C-2021、GB/T 20157-2006《信息技术 软件维护》及 [14] 模板正文用法整理。全文术语必须与本表保持一致；首次出现时用"中文全称（英文缩写）"格式。

## 配置管理与标识

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 计算机软件配置项 | CSCI（Computer Software Configuration Item） | 软件配置项，本文档可靠性设计与维护性设计的对象。 |
| 硬件配置项 | HWCI（Hardware Configuration Item） | 与 CSCI 对应的硬件配置项；移交、环境资源分析时涉及。 |
| 计算机软件部件 | CSC（Computer Software Component） | CSCI 设计中的元素：类、对象、模块、函数、例程或数据库。 |
| 计算机软件单元 | CSU（Computer Software Unit） | CSCI 设计中可单独测试的最小软件元素；避错设计中单元测试覆盖的对象。 |
| 基线 | Baseline | 经正式评审确认的文档/产品版本，后续更改受配置管理控制。 |
| 文档标识号 | — | 格式示例 `TN/x-DO-DS-V{N.xx}`，见 1.1 节。 |

## 可靠性与维护性专用（本文档高频）

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 可靠性 | Reliability | 软件在规定条件下、规定时间内完成规定功能的能力，第 3 章设计目标。 |
| 可维护性 | Maintainability | 软件可被修改、被测试、被恢复的能力，第 4 章设计目标。 |
| 平均故障间隔时间 | MTBF（Mean Time Between Failures） | 可靠性量化指标，余量与容错设计判据。 |
| 平均修复时间 | MTTR（Mean Time To Repair） | 可维护性量化指标，错误恢复设计判据。 |
| 容错 | Fault Tolerance | 软件在故障存在时继续提供规定功能的能力，3.5。 |
| 避错 | Fault Avoidance | 通过评审、分析、规范预防故障引入，3.4。 |
| 冗余设计 | Redundancy Design | 双机热备、双通道校验、多副本等提高可靠性的设计，3.2。 |
| 健壮性 | Robustness | 软件在异常输入、边界条件下不崩溃的能力，3.3。 |
| 圈复杂度 | Cyclomatic Complexity | 结构复杂度控制量化指标，3.1。 |
| 回归测试 | Regression Testing | 修改后重跑既有测试用例验证未引入新缺陷，4.1.5。 |
| 维护类型 | — | 改正性、适应性、完善性、预防性四类维护，4.4.1。 |
| 维护概念 | Maintenance Concept | 交付后维护任务、机构、过程的顶层描述，4.4。 |
| 退役 | Retirement | 软件结束使用生存周期时的受控终止过程，4.8。 |

## 通用软件术语（按源码实际出现选用）

> 纯软件、信息化项目正文中高频出现的通用术语。首次出现写"中文全称（英文缩写）"，此后用缩写；源码中未出现的不得收录。

| 术语 | 英文/缩写 | 规范写法与使用场景 |
|------|-----------|----------------|
| JavaScript 对象表示法 | JSON（JavaScript Object Notation） | 数据交换格式；接口数据元素、配置文件的默认格式。 |
| 超文本传输协议 | HTTP（Hypertext Transfer Protocol） | 接口通信协议；注明方法（GET/POST）、状态码。 |
| 应用程序编程接口 | API（Application Programming Interface） | 对外接口的统称。 |
| 软件配置管理 | SCM（Software Configuration Management） | 基线、变更控制相关活动，4.3 文档编制引用。 |
| 数据库管理系统 | DBMS（Data Base Management System） | 环境资源分析（4.6.2）涉及的支撑软件。 |

## 术语裁剪指引

- 只收录正文实际出现的术语；「通用软件术语」一表按源码实际出现选用，不得为凑数整表照搬。
- 不含硬件配置项（HWCI）的纯软件项目：正文不涉及硬件时，可不收 HWCI 相关条目，但 **CSCI 与本文档类型必须保留**。
- 本文档不规定合格性方法与合格性级别（那是 SRS/测试文档的内容），正文不得引入"合格性方法 A-演示"类术语；4.1.5 的"符合性测试"按 GB/T 8566 表述。
