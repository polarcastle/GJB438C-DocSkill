# 军用软件文档常用术语表（[05] 软件标准化大纲适用）

> 术语依据 GJB 438C-2021 及 [05] 模板正文用法整理。全文术语必须与本表保持一致；首次出现时用"中文全称（英文缩写）"格式。

## 标准化工作核心术语（本大纲高频）

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 软件标准化大纲 | — | 规定软件产品标准化目标、标准实施要求、标准化文件体系和研制各阶段标准化工作的顶层文件，即本文档。 |
| 标准化系数 | — | 产品标准化期望达到水平的度量：符合标准的部件（要素）数与总部件数之比，以百分比表述（3.2 a））。 |
| 通用化 / 系列化 / 组合化 | — | "三化"程度：零部件跨产品通用、按尺寸参数分档成系列、以通用单元组合成产品；标准化目标的核心度量（3.2 a））。 |
| 重大标准 | — | 贯彻实施涉及面宽、难度大、经费投资大、组织协调复杂、影响战术技术指标或与安全关系密切的标准（4.3）。 |
| 重大标准贯彻实施方案 | — | 对重大标准进行综合分析后提出的实施方案，内容包括范围效果分析、重点内容及剪裁意见、难点及解决途径等（4.3）。 |
| 标准选用范围 | — | 产品研制时对设计人员选用标准的推荐性规定；所列标准须经图样和技术文件采用方能直接指导生产或验收（4.4）。 |
| 剪裁 | Tailoring | 按产品实际对标准内容进行删减、调整的活动，须按 GJB/Z 69 规定的选用和剪裁要求执行（4.2 a））。 |
| 标准化文件体系表 | — | 描述研制各阶段所需标准化文件层次与构成关系的表（5.2）。 |
| 标准化文件项目表 | — | 按体系表编制的文件清单，含文件名称、作用、界面和适用范围、主要内容、协调说明（5.2）。 |
| 文件更改记录 | — | 记录文档版本、页次、标记、处数、更改文件号、更改者和日期的表格（封面后第一张表，首版不填）。 |

## 配置管理与标识

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 计算机软件配置项 | CSCI（Computer Software Configuration Item） | 软件配置项，软件产品树上接受配置管理的基本对象。 |
| 基线 | Baseline | 经正式评审确认的文档/产品版本，后续更改受配置管理控制。 |
| 文档标识号 | — | 格式示例 `TN/x-DO-DS-V{N.xx}`，见 1.1 节与封面。 |
| 配置管理 | CM（Configuration Management） | 标识、控制、记录和审计配置项的活动，标准化文件更改审批、会签、备案的依据。 |

## 文档类型

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 军用软件开发文档通用要求 | GJB 438C-2021 | 军用软件开发文档（含本大纲）编制的通用标准，本大纲引用的首要标准。 |
| 军用软件研制能力成熟度模型 | GJB 5000A | 软件过程能力评价标准，标准实施要求的依据之一。 |
| 软件开发计划 | SDP（Software Development Plan） | 7.3 d）要求文档名称与软件开发计划中给出的名称一致。 |
| 软件需求规格说明 | SRS（Software Requirements Specification） | [08] 文档，研制阶段标准化文件体系表的组成部分。 |
| 软件概要设计说明 | SDD（Software Design Description） | [10] 文档，研制阶段标准化文件体系表的组成部分。 |

## 通用软件术语（按项目实际出现选用）

> 纯软件项目正文中高频出现的通用术语。首次出现写"中文全称（英文缩写）"，此后用缩写；项目中未出现的不得收录。

| 术语 | 英文/缩写 | 规范写法与使用场景 |
|------|-----------|----------------|
| 应用程序编程接口 | API（Application Programming Interface） | 对外接口的统称。 |
| JavaScript 对象表示法 | JSON（JavaScript Object Notation） | 数据交换格式；接口数据元素、消息体的默认格式。 |
| 超文本传输协议 | HTTP（Hypertext Transfer Protocol） | 接口通信协议；注明方法（GET/POST）、状态码。 |
| 软件配置管理 | SCM（Software Configuration Management） | 基线、变更控制相关活动。 |

## 术语裁剪指引

- 只收录正文实际出现的术语；「通用软件术语」一表按项目实际出现选用，不得为凑数整表照搬。
- 本大纲为管理类文档：CSCI/CSC/CSU 等设计类术语除非正文实际涉及，否则不收录；合格性方法、需求追踪等 SRS 专用术语不适用。
- 通用术语与 GJB 术语定义冲突时，以本表 GJB 定义为准，正文避免混用。
- 标准编号引用保持模板原文拼写（如 GJB/Z 69 在模板中写作 GJB/z69），不得擅自"纠正"为检索不到的编号。
