# 军用软件文档常用术语表（[23] 软件变更报告适用）

> 术语依据 GJB 438C-2021 及 [23] 模板正文用法整理。全文术语必须与本表保持一致；首次出现时用"中文全称（英文缩写）"格式。

## 配置管理与标识

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 计算机软件配置项 | CSCI（Computer Software Configuration Item） | 软件配置项，变更报告所针对软件对象的配置管理单位。 |
| 基线 | Baseline | 经正式评审确认的文档/产品版本，变更以基线为比较对象（现行版本即上一基线）。 |
| 更动 | Change | 本模板用语，指对现行软件或文档的新建或修改；全文统一用"更动"，不与"变更"混用（文档名除外）。 |
| 项目唯一的标识符 | — | 接口、需求、更动项等的唯一编号，用于全项目追踪。 |
| 文档标识号 | — | 格式示例 `TN/x-DO-DS-V{N.xx}`，见 1.1 节。 |
| 版次 | — | 文档封面字段（A 版/B 版……），与软件版本号区分。 |

## 文档类型

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 软件变更报告 | SCR（Software Change Report） | [23] 本文档，描述更动理由、更动实质、修改后方案、运行场景与影响分析。 |
| 软件需求规格说明 | SRS（Software Requirements Specification） | 现行软件需求来源文档，第 2 章常引用。 |
| 软件概要设计说明 | SDD（Software Design Description） | 现行软件设计方式来源文档，第 3 章描述设计方式时引用。 |
| 软件研制任务书 | — | 变更任务来源文件。 |
| 软件配置管理计划 | SCMP（Software Configuration Management Plan） | 更动受配置管理控制的依据。 |

## 变更相关（本文档核心）

| 术语 | 含义与使用场景 |
|------|----------------|
| 现行软件 | 变更前的软件基线版本，第 3 章描述对象。 |
| 更动优先级别 | 本质的 / 期望的 / 可选的三级划分，4.3 节使用；期望和可选的更动需另给优先级别。 |
| 更动因素 | 引发更动的用户需要、威胁、任务、目标、环境、接口、人员等因素，4.1 节 a 项。 |
| 运行场景 | 第 6 章用语：举例说明软件作用、与用户的交互、与其它软件的接口，含事件、动作、激励源、信息、交互。 |
| 影响分析 | 第 7 章：从运行、组织、开发期间三方面评估更动对用户、需方、开发方和保障机构的影响。 |
| 运行方式 | 软件运行条件类别（常规、维护、培训、降级、紧急事件、备选场点、战时、平时等），5.3 节。 |
| 保障方案 | 5.5 节：保障机构、设施、设备、支持软件、维修/更换标准、维护等级和周期、存储分配供应方法。 |
| 并行运行 | 新软件与现有软件同时运行对比验证的活动，7.3 节。 |

## 相关方

| 术语 | 含义与使用场景 |
|------|----------------|
| 需方 / 用户 / 开发方 / 保障机构 | 项目的四类相关方：需求提出方、软件使用者、软件开发方、维护保障组织，第 3、7 章标识。 |
| 运行现场 | 软件部署使用的地点/环境。 |

## 通用软件术语（非军用专属，按源码实际出现选用）

> 纯软件、信息化项目正文中高频出现的通用术语。首次出现写"中文全称（英文缩写）"，此后用缩写；源码中未出现的不得收录。

| 术语 | 英文/缩写 | 规范写法与使用场景 |
|------|-----------|----------------|
| 应用程序编程接口 | API（Application Programming Interface） | 对外接口的统称。 |
| JavaScript 对象表示法 | JSON（JavaScript Object Notation） | 数据交换格式；接口数据元素、消息体的默认格式。 |
| 超文本传输协议 | HTTP（Hypertext Transfer Protocol） | 接口通信协议；注明方法（GET/POST）、状态码。 |
| 软件配置管理 | SCM（Software Configuration Management） | 基线、变更控制相关活动。 |

## 术语裁剪指引

- 只收录正文实际出现的术语（与 `generation_prompt` 的要求一致）；「通用软件术语」一表按源码实际出现选用，不得为凑数整表照搬。
- 本文档不涉及合格性方法（演示/测试/分析/检查/特殊方法）等 SRS 专用术语，除非变更内容本身引用 SRS 相关文档，否则不收。
- 通用术语与 GJB 术语定义冲突时，以本表 GJB 定义为准，正文避免混用。
