# 军用软件文档常用术语表（[30] 软件安全性设计适用）

> 术语依据 GJB 438C-2021、[30] 模板正文用法及安全性设计常用标准整理。全文术语必须与本表保持一致；首次出现时用"中文全称（英文缩写）"格式。

## 配置管理与标识

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 计算机软件配置项 | CSCI（Computer Software Configuration Item） | 软件配置项，安全性设计、验证与更改管理的基本对象。 |
| 硬件配置项 | HWCI（Hardware Configuration Item） | 与 CSCI 对应的硬件配置项；硬件与软件功能分配、接口设计涉及。 |
| 计算机软件部件 | CSC（Computer Software Component） | CSCI 设计中的元素：类、对象、模块、函数、例程或数据库。 |
| 计算机软件单元 | CSU（Computer Software Unit） | CSCI 设计中可单独测试的最小软件元素。 |
| 基线 | Baseline | 经正式评审确认的文档/产品版本，后续更改受配置管理控制；软件更改要求一节引用。 |
| 文档标识号 | — | 格式示例 `TN/x-DO-DS-V{N.xx}`，见 1.1 节。 |

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|

## 安全性设计专用

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 安全关键软件 | Safety-Critical Software | 故障可能导致人员伤亡、重大财产损失的软件；按附录B的 A/B 级准则标识（3.1.7）。 |
| 安全性内核 | Safety Kernel | 独立运行的监视程序，防止系统进入不安全状态，必要时将系统转移到规定的安全状态（3.1.3）。 |
| 故障安全状态 | Fail-Safe State | 系统出现故障时转入的预定安全状态；无意跳转、接口故障等条款要求恢复到此状态。 |
| 失效容限 | Fault Tolerance | 系统容许的故障数量；依据软件安全关键等级确定冗余要求（3.6.1）。 |
| N版本程序设计 | N-Version Programming | N 个相异程序加表决器的容错结构；分随机相异与强制相异（3.6.1.2）。 |
| 恢复块 | Recovery Block | 基本块＋替换块＋接受测试的容错结构，N版本不可行时的替代（3.6.1.3）。 |
| 三取二表决 | 2-out-of-3 Voting | 三模存储访问的裁决方式（3.6.2）。 |
| 监控定时器 | Watchdog Timer | 监视程序超时与死循环的独立硬件定时器（3.8.2）。 |
| 多余物 | Extraneous Material | 文档未记载的特征、不使用的代码/变量、未初始化内存等应清除的对象（3.14）。 |
| 回归测试 | Regression Test | 软件更改后必须进行的测试，验证未引入新的缺陷（3.15）。 |

## 软件工程通用术语

> 纯软件、信息化项目正文中高频出现的通用术语。首次出现写"中文全称（英文缩写）"，此后用缩写；正文未出现的不得收录。

| 术语 | 英文/缩写 | 规范写法与使用场景 |
|------|-----------|----------------|
| JavaScript 对象表示法 | JSON（JavaScript Object Notation） | 数据交换格式；配置数据、记录文件的格式说明。 |
| 超文本传输协议 | HTTP（Hypertext Transfer Protocol） | 接口通信协议；注明方法（GET/POST）、状态码。 |
| 应用程序编程接口 | API（Application Programming Interface） | 对外接口的统称。 |
| 软件配置管理 | SCM（Software Configuration Management） | 基线、变更控制相关活动（3.15）。 |
| 圈复杂度 | McCabe Index | 软件单元结构复杂度指标，应小于 10（3.13.4）。 |
| 电可擦除可编程只读存储器 | EEPROM（Electrically Erasable Programmable Read-Only Memory） | 需少量次数修改的重要信息存储介质（3.12.11）。 |
| 只读存储器 | ROM（Read-Only Memory） | 不易丢失的重要信息存储介质（3.12.11）。 |
| 随机存取存储器 | RAM（Random Access Memory） | 重要程序与数据的运行存储介质，三模存储（3.6.2）。 |

## 术语裁剪指引

- 只收录正文实际出现的术语（与第 3 章各节 `generation_prompt` 的要求一致）；「通用术语」一表按项目实际出现选用，不得为凑数整表照搬。
- 模板原文中的明显排字误差（如"藕合"应为"耦合"、"内顺"应为"内聚"、"公共变"应为"公共变量"）在锚点中必须逐字保留模板原文，正文 content 中使用正确写法。
- 通用术语与 GJB 术语定义冲突时，以 GJB 定义为准，正文避免混用。
