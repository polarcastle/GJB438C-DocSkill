# 军用软件文档常用术语表（[16] STD 适用）

> 术语依据 GJB 438C-2021 及 [16] 模板正文用法整理。全文术语必须与本表保持一致；首次出现时用"中文全称（英文缩写）"格式。

## 配置管理与标识

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 计算机软件配置项 | CSCI（Computer Software Configuration Item） | 第 5 章可追踪性中"CSCI 需求"的归属单位；CSCI 测试时追踪到 SRS/IRS 中的需求。 |
| 项目唯一的标识符 | — | 测试（TST-XX）、测试用例（TC-XX）、需求的唯一编号；第 3、4、5 章强制要求。 |
| 被测件 | Item Under Test | 接受测试的软件实体（含版本），第 3 章软件准备的对象。 |
| 基线 | Baseline | 经正式评审确认的版本，被测件从配置库提取时须核对基线版本。 |
| 配置项 | CI（Configuration Item） | 纳入配置管理的实体，被测件按配置项管理。 |

## 文档类型

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 软件测试说明 | STD（Software Test Description） | [16] 本文档，规定测试准备与测试说明。 |
| 软件测试计划 | STP（Software Test Plan） | 测试依据之一，本文档测试项与用例应与 STP 协调一致。 |
| 软件需求规格说明 | SRS（Software Requirements Specification） | 测试输入文档；第 4 章用例涉及的需求、第 5 章追踪的目标。 |
| 软件概要设计说明 | SDD（Software Design Description） | 理解被测件结构的参考文档，可作引用文档列出。 |
| 系统/子系统规格说明 | SSS（System/Subsystem Specification） | 系统测试时第 5 章 b）项追踪的系统需求来源。 |
| 接口需求规格说明 | IRS（Interface Requirements Specification） | 系统测试时与 SSS 并列的追踪来源。 |

## 测试相关

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 测试项/测试 | Test | 第 3、4 章的分条单位（3.X、4.X），用项目唯一的标识符标识。 |
| 测试用例 | TC（Test Case） | 4.X.Y 条的对象：为一组测试目标设计的输入、先决条件、预期结果与规程。 |
| 测试规程 | Test Procedure | 按执行步骤顺序排列的独立编号步骤，4.X.Y.6。 |
| 先决条件 | Precondition | 执行用例前必须具备的软件/硬件配置与初始状态，4.X.Y.2。 |
| 测试输入 | Test Input | 用例所需的数据、信号或事件，4.X.Y.3。 |
| 预期结果 | Expected Result | 测试执行前定义的判定依据输出（中间结果与最终结果），4.X.Y.4。 |
| 评价准则 | Evaluation Criterion | 判定测试结果可否接受的量化/定性准则，4.X.Y.5。 |
| 再测试 | Retest | 结果不确定或不成功时按规程重复测试，4.X.Y.5 f）、4.X.Y.6 步骤 8)。 |
| 可追踪性 | Traceability | 测试用例与系统/CSCI 需求的双向关联，第 5 章。 |

## 通用软件术语（非军用专属，按源码实际出现选用）

> 纯软件、信息化项目正文中高频出现的通用术语。首次出现写"中文全称（英文缩写）"，此后用缩写；源码中未出现的不得收录。

| 术语 | 英文/缩写 | 规范写法与使用场景 |
|------|-----------|----------------|
| JavaScript 对象表示法 | JSON（JavaScript Object Notation） | 测试输入数据文件格式；测试输入章节描述数据文件时使用。 |
| 超文本传输协议 | HTTP（Hypertext Transfer Protocol） | 被测件对外接口协议；涉及接口测试输入/预期结果时注明方法与状态码。 |
| 应用程序编程接口 | API（Application Programming Interface） | 被测件对外接口的统称。 |
| 结构化查询语言 | SQL（Structured Query Language） | 涉及数据库/数据文件测试输入时使用。 |
| 软件配置管理 | SCM（Software Configuration Management） | 被测件版本提取与基线核对的依据。 |

## 术语裁剪指引

- 只收录正文实际出现的术语（与第 6 章 `generation_prompt` 的要求一致）；「通用软件术语」一表按源码实际出现选用，不得为凑数整表照搬。
- 无硬件被测件的项目不收硬件专用术语；涉及硬件在环测试时保留硬件准备相关表述。
- 通用术语与 GJB 术语定义冲突时，以本表 GJB 定义为准，正文避免混用。
