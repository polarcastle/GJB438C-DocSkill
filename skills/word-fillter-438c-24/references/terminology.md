# 军用软件文档常用术语表（[24] SVD 适用）

> 术语依据 GJB 438C-2021 及 [24] 模板正文用法整理。全文术语必须与本表保持一致；首次出现时用"中文全称（英文缩写）"格式。

## 配置管理与标识

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 计算机软件配置项 | CSCI（Computer Software Configuration Item） | 软件配置项，版本发布与配置管理的基本对象。 |
| 基线 | Baseline | 经正式评审确认的文档/产品版本，后续更改受配置管理控制。SVD 描述的每个版本对应一个受控基线。 |
| 文档标识号 | — | 格式示例 `TN/x-DO-DS-V{N.xx}`，见 1.1 节。 |
| 问题报告 | PR（Problem Report） | 记录软件问题的报告，3.3 更改说明要求标识与更改相关的问题报告。 |
| 更改建议 | CR（Change Request） | 提出更改的建议，3.3 要求标识与更改相关的更改建议。 |
| 更改通告 | — | 批准并通告更改的文件，3.3 要求标识与更改相关的更改通告。 |
| 发布号 | Release Number | 同一版本号下标识软件发布顺序的编号，与版本号配合使用（如 Release 1）。 |

## 文档类型

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 软件版本说明 | SVD（Software Version Description） | [24] 本文档，描述软件版本的发布内容、安装方法和已知问题。 |
| 软件需求规格说明 | SRS（Software Requirements Specification） | [08] 需求文档，3.5 有关的文档常引用。 |
| 软件概要设计说明 | SDD（Software Design Description） | [10] 概要设计文档，3.5 有关的文档常引用。 |
| 软件开发计划 | SDP（Software Development Plan） | 项目开发计划文档。 |
| 软件研制任务书 | — | 研制任务来源文件。 |

## 版本发布相关（SVD 第 3 章专用）

| 术语 | 含义与使用场景 |
|------|----------------|
| 物理媒体 | 承载软件版本的实物载体，如列表、磁带、磁盘、光盘、U盘等，3.1 发布的材料清单按六要素列出。 |
| 适应性数据 | 随安装现场不同而变化的现场专用数据（如场地经纬度、赋税代码），3.4 标识或引用；首版之后须描述其更改。 |
| 已知错误 | 软件发布时已经确认但尚未纠正的错误，3.7 列出并给出规避/纠正措施。 |
| 用户机构 / 保障机构 | SVD 的两类预期接受者：用户机构需要避免错误的建议，保障机构需要改正错误的建议，3.7 注明。 |
| 复制与许可证条款 | 对发布介质和文档的复制许可约束，3.1 必须给出说明。 |

## 通用软件术语（非军用专属，按源码实际出现选用）

> 纯软件、信息化项目正文中高频出现的通用术语。首次出现写"中文全称（英文缩写）"，此后用缩写；源码中未出现的不得收录。

| 术语 | 英文/缩写 | 规范写法与使用场景 |
|------|-----------|----------------|
| 应用程序编程接口 | API（Application Programming Interface） | 对外接口的统称。 |
| JavaScript 对象表示法 | JSON（JavaScript Object Notation） | 配置/数据文件格式说明时使用。 |
| 超文本传输协议 | HTTP（Hypertext Transfer Protocol） | 软件含网络通信功能时说明协议使用。 |
| 软件配置管理 | SCM（Software Configuration Management） | 基线、变更控制、版本发布相关活动。 |

## 纯软件项目（无 HWCI）的术语裁剪指引

- 无硬件配置项（HWCI）的纯软件项目：正文不涉及硬件时，术语表不收 HWCI、物理兼容性等硬件/机电相关术语；**CSCI、SVD 及版本发布相关术语必须保留**。
- 裁剪原则：只收录正文实际出现的术语（与第 4 章 `generation_prompt` 的要求一致）；「通用软件术语」一表按源码实际出现选用，不得为凑数整表照搬。
- 通用术语与 GJB 术语定义冲突时，以本表 GJB 定义为准，正文避免混用。
