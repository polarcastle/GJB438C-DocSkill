# 军用软件文档常用术语表（[19] STR 适用）

> 术语依据 GJB 438C-2021 及 [19] 模板正文用法整理。全文术语必须与本表保持一致；首次出现时用"中文全称（英文缩写）"格式。

## 配置管理与标识

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 计算机软件配置项 | CSCI（Computer Software Configuration Item） | 被测软件的划分单位；被测对象为配置项时，标识、追踪均以 CSCI 为单位。 |
| 项目唯一的标识符 | — | 测试项、测试用例、问题报告的强制编号规则（如 ST-FUN-001、TC-FUN-003、PRWDD-003），全文唯一且前后一致。 |
| 基线 | Baseline | 经正式评审确认的版本，后续更改受控；测试对象为基线版本软件。 |
| 软件配置管理 | SCM（Software Configuration Management） | 基线、变更控制相关活动；问题/更改报告的处理渠道。 |
| 回归测试 | Regression Test | 软件更改后，为确认更改未引入新问题而重新执行的测试；统计表按回归轮次统计问题处置情况。 |

## 文档类型

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 软件测试报告 | STR（Software Test Report） | [19] 本文档，记录测试环境、执行过程、结果与结论。 |
| 软件需求规格说明 | SRS（Software Requirements Specification） | 测试依据；需求符合性判断与"未得到满足的需求"标识均回指 SRS 章节号。 |
| 软件测试计划 | STP（Software Test Plan） | 引用文档；测试项、测试用例与测试轮次的策划出处。 |
| 软件测试规程 | STD（Software Test Description） | 引用文档；测试用例执行步骤的出处，4.X.2.Y b）项引用其步骤号。 |
| 软件测试用例说明 | STC（Software Test Case） | 视项目文档体系引用；测试用例的详细定义文档。 |

## 测试相关

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 测试项 | Test | 一组相关测试用例的集合；[19] 模板第 4 章按测试项（4.X）组织详细测试结果。 |
| 测试用例 | TC（Test Case） | 为特定测试目标设计的一组输入、执行条件和预期结果；完成状态分"所有结果都如预期的那样/遇到的问题/与要求有偏差"。 |
| 测试规程 | Test Procedure | 规定测试用例执行步骤、顺序和操作的文档。 |
| 测试环境 | Test Environment | 执行测试所用的硬件、软件、数据及人员的组合；第 3.2 条与操作环境对比。 |
| 操作环境 | Operational Environment | 软件实际部署运行的环境。 |
| 问题/更改报告 | PCR（Problem/Change Report） | 记录测试发现的问题及更改活动的报告；遗留缺陷必须给出报告编号。 |
| 问题类型 | — | 统计表列项：功能缺失、功能错误、界面问题、其它。 |
| 问题等级 | — | 统计表列项：致命问题、严重问题、一般问题、建议改进。 |
| 完成状态 | — | 4.X.1 对每个测试用例的结论：如预期/遇到问题/与要求有偏差。 |
| 偏差 | Deviation | 测试执行与测试用例/规程的不一致；4.X.3.Y 描述偏差说明、理由与有效性评估。 |

## 通用软件术语（非军用专属，按源码实际出现选用）

> 纯软件、信息化项目正文中高频出现的通用术语。首次出现写"中文全称（英文缩写）"，此后用缩写；源码中未出现的不得收录。

| 术语 | 英文/缩写 | 规范写法与使用场景 |
|------|-----------|----------------|
| 应用程序编程接口 | API（Application Programming Interface） | 接口测试对象的统称。 |
| JavaScript 对象表示法 | JSON（JavaScript Object Notation） | 接口测试数据的交换格式。 |
| 超文本传输协议 | HTTP（Hypertext Transfer Protocol） | 接口测试的通信协议；注明方法与状态码。 |
| 中央处理器 | CPU（Central Processing Unit） | 性能测试指标（占用率、主频）描述。 |
| 数据库 | DB（DataBase） | 涉及数据一致性测试时使用。 |

## 纯软件项目（无 HWCI）的术语裁剪指引

- 无硬件配置项（HWCI）的纯软件项目：正文不涉及硬件时，术语表不收 HWCI 等硬件相关术语；但 **CSCI（被测对象划分）、本文档类型（STR）及测试用例/测试项/问题等级统计口径必须保留**。
- 裁剪原则：只收录正文实际出现的术语（与第 5 章 `generation_prompt` 的要求一致）；「通用软件术语」一表按源码实际出现选用，不得为凑数整表照搬。
- 通用术语与 GJB 术语定义冲突时，以本表 GJB 定义为准，正文避免混用。
