# 军用软件文档常用术语表（[09] IRS 适用）

> 术语依据 GJB 438C-2021 及 [09] 模板正文用法整理。全文术语必须与本表保持一致；首次出现时用"中文全称（英文缩写）"格式。

## 配置管理与标识

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 计算机软件配置项 | CSCI（Computer Software Configuration Item） | 软件配置项，接口需求规格说明的基本对象；本文档描述的接口实体常为一个 CSCI 或系统。 |
| 硬件配置项 | HWCI（Hardware Configuration Item） | 与 CSCI 对应的硬件配置项；涉及硬件接口时可作为接口实体出现。 |
| 项目唯一的标识符 | — | 接口、数据元素等项的唯一编号，全项目追踪使用。本文档每个接口、每个数据元素都必须给出。 |
| 基线 | Baseline | 经正式评审确认的文档/产品版本，后续更改受配置管理控制。 |
| 文档标识号 | — | 格式示例 `TN/x-DO-DS-V{N.xx}`，见 1.1 节。 |
| 接口实体 | Interface Entity | 参与接口并共享、提供或交换数据的系统、配置项、用户等，IRS 第 3 章需求的施加对象。 |

## 文档类型

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 接口需求规格说明 | IRS（Interface Requirements Specification） | [09] 本文档，规定接口实体间的接口需求。 |
| 软件需求规格说明 | SRS（Software Requirements Specification） | [08] 需求文档；IRS 的追踪来源（第 5 章正向/反向追踪到系统需求）。 |
| 软件概要设计说明 | SDD（Software Design Description） | [10] 概要设计文档，与 IRS 配套使用。 |
| 接口设计说明 | IDD（Interface Design Description） | 接口设计信息可引用 IDD 代替详述，IRS 第 3 章注明。 |
| 数据字典 | — | 数据元素名称、类型、取值等的集中定义，IRS 第 3 章可引用代替详述。 |

## 合格性（IRS 第 4 章专用）

| 术语 | 含义与使用场景 |
|------|----------------|
| 合格性方法 | 验证接口实体满足需求的方法，五类：演示、测试、分析、审查、特殊的合格性方法。IRS 模板未设置合格性级别列（与 SRS 不同）。 |
| ├ 演示 | 不使用仪器、专用测试设备或事后分析，依靠可见的功能操作直接运行接口实体。 |
| ├ 测试 | 使用仪器或专用测试设备运行接口实体，采集数据供事后分析。 |
| ├ 分析 | 处理从其它合格性方法获得的积累数据（简约、解释、推断）。 |
| ├ 审查 | 对接口实体、文档等进行目视检查。 |
| └ 特殊的合格性方法 | 专用工具、技术、规程、设施、验收限制。 |

## 接口需求相关

| 术语 | 含义与使用场景 |
|------|----------------|
| 接口优先级 | 施加于接口的需求的相对重要程度，第 3 章每个接口必写。 |
| 数据元素 | 接口实体间传送的数据基本单元；特性含名称/标识、数据类型、大小和格式、计量单位、取值范围或枚举、准确性和精度、约束条件、保密性约束、来源和接收者。 |
| 数据元素包 | 数据元素的组合体：记录、消息、文件、数组、显示、报表等；特性含结构、介质、视听特性、包间关系、约束、保密性、来源和接收者。 |
| 接口图 | 描述接口实体及接口关系的图，（若适用）在 3.1 节给出。 |
| 通信方法 | 接口实体用于接口的链路/带宽/频率/介质、消息格式、流控制、传送速率、路由寻址、传输服务与安全保密考虑。 |
| 协议 | 接口实体用于接口的协议的层次、打包、合法性检查/错误控制/恢复、同步、状态与标识报告。 |
| 双向追踪 | 正向（本文档需求→系统/子系统需求）与逆向（系统/子系统需求→本文档需求），第 5 章。 |
| 系统级/子系统级接口实体 | 第 5 章适用范围分界：系统级实体本章不适用，子系统级或更低级实体须给出双向追踪。 |
| 需方 / 开发方 / 保障机构 | 项目的三类相关方，1.2 节标识。 |
| 运行现场 | 软件部署使用的地点/环境，区分当前和计划的。 |

## 通用软件术语（非军用专属，按源码实际出现选用）

> 纯软件、信息化项目正文中高频出现的通用术语。首次出现写"中文全称（英文缩写）"，此后用缩写；源码中未出现的不得收录。

| 术语 | 英文/缩写 | 规范写法与使用场景 |
|------|-----------|----------------|
| 应用程序编程接口 | API（Application Programming Interface） | 对外接口的统称；描述接口类型时使用。 |
| JavaScript 对象表示法 | JSON（JavaScript Object Notation） | 数据交换格式；接口数据元素、消息体的默认格式。 |
| 超文本传输协议 | HTTP（Hypertext Transfer Protocol） | 接口通信协议；注明方法（GET/POST）、状态码。 |
| 表述性状态转移 | REST（Representational State Transfer） | HTTP 资源接口风格；写接口类型时使用，如"REST 接口"。 |
| 用户数据报协议 | UDP（User Datagram Protocol） | 无连接网络传输协议；写通信方法时使用。 |
| 传输控制协议 | TCP（Transmission Control Protocol） | 面向连接的网络传输协议；写通信方法时使用。 |
| 循环冗余校验 | CRC（Cyclic Redundancy Check） | 数据包校验手段；写协议特性时使用。 |
| 远程过程调用 | RPC（Remote Procedure Call） | JSON-RPC 等远程调用协议的上位概念。 |
| 软件配置管理 | SCM（Software Configuration Management） | 基线、变更控制相关活动。 |

## 纯软件项目（无 HWCI）的术语裁剪指引

- 无硬件配置项（HWCI）的纯软件项目：正文不涉及硬件时，术语表不收 HWCI、物理兼容性等硬件/机电相关术语；但 **CSCI、接口实体与本文档类型（IRS）必须保留**。
- 裁剪原则：只收录正文实际出现的术语（与第 6 章 `generation_prompt` 的要求一致）；「通用软件术语」一表按源码实际出现选用，不得为凑数整表照搬。
- 通用术语与 GJB 术语定义冲突时，以本表 GJB 定义为准，正文避免混用。
