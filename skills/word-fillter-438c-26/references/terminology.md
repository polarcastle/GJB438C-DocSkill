# 军用软件文档常用术语表（[26] 软件质量保证报告适用）

> 术语依据 GJB 438C 及 [26] 模板正文用法整理。全文术语必须与本表保持一致；首次出现时用"中文全称（英文缩写）"格式。

## 配置管理与标识

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 计算机软件配置项 | CSCI（Computer Software Configuration Item） | 软件配置项，质量保证活动的对象；本文档中"软件""产品"一般指 CSCI。 |
| 基线 | Baseline | 经正式评审确认并受配置管理控制的文档/产品版本，分功能基线和产品基线，4.4 节主题。 |
| 开发库 / 受控库 / 产品库 | — | 配置管理三库，4.4 节必写；产品库存放经配置审核合格的交付物。 |
| 配置审核 | — | 交付物入库前对其完整性和一致性的审核，4.4 节。 |
| 文档标识号 | — | 格式由项目约定（示例 `XT-SQAR-V1.0`），见 1.1 节，与封面一致。 |
| 受控文档 | — | 纳入配置管理、更改需履行审批手续的文档，第 2 章引用文档的属性。 |

## 文档类型

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 软件质量保证报告 | SQAR（Software Quality Assurance Report） | [26] 本文档，报告研制过程质量保证实施情况。 |
| 软件质量保证计划 | SQAP（Software Quality Assurance Plan） | 质量保证工作的策划文件，本文档各章事实依据，3.2/4/5/7 章引用。 |
| 软件配置管理计划 / 报告 | SCMP / SCMR（Software Configuration Management Plan/Report） | 配置管理策划与实施报告，2 章、4.1.5、4.4 引用。 |
| 软件开发计划 | SDP（Software Development Plan） | 研制过程策划文件，4.1.1 引用。 |
| 软件需求规格说明 | SRS（Software Requirements Specification） | 需求和确认准则的出处，2 章、3.3、4.1.2 引用。 |
| 软件概要设计说明 | SDD（Software Design Description） | 设计评审对象，2 章、4.1.4 引用。 |
| 软件测试说明 / 软件测试报告 | STD / STR | 测试过程与结果文档，2 章、4.2、4.3.2 引用。 |
| 可行性研究报告 / 研制任务书 | — | 质量要求（3.3）与战术技术指标的来源文件。 |

## 质量保证活动

| 术语 | 含义与使用场景 |
|------|----------------|
| 质量保证工作组 | 项目组内实施质量管理的组织，3.1 节必写其建立与成员职责。 |
| 质量特性 | 功能性、可靠性、易用性、效率、维护性、可移植性，4.1.1 策划内容。 |
| 质量审核 | 按质量保证计划对文档、过程、产品的系统性检查，第 7 章。 |
| 质量监督 | 对研制活动（评审、测试、进度）的跟踪检查，第 7 章。 |
| 评审 / 归零 | 阶段正式评审及评审问题的"提出—修改—验证—关闭"闭环；问题"归零"是军用质量惯用语。 |
| 标审 | 标准化审查，文档编制（4.3.1）的必经环节。 |
| 第三方测评 | 由独立于开发方的具备资质测评机构实施的测评，4.6 节；不得写具体机构名称（除非用户提供）。 |
| 测试覆盖率 | 测试用例对软件需求的覆盖程度，4.2 节量化指标，须给出实测值。 |
| 风险监控 | 风险识别、分析评估、应对措施制定与跟踪，第 5 章。 |
| 三库控制 | 开发库、受控库、产品库的访问与更改控制，4.4 节。 |

## 通用软件术语（非军用专属，按项目实际出现选用）

> 纯软件、信息化项目正文中高频出现的通用术语。首次出现写"中文全称（英文缩写）"，此后用缩写；项目实际未出现的不得收录。

| 术语 | 英文/缩写 | 规范写法与使用场景 |
|------|-----------|----------------|
| JavaScript 对象表示法 | JSON（JavaScript Object Notation） | 数据交换格式；接口数据、消息体的默认格式。 |
| 超文本传输协议 | HTTP（Hypertext Transfer Protocol） | 接口通信协议；注明方法（GET/POST）、状态码。 |
| 应用程序编程接口 | API（Application Programming Interface） | 对外接口的统称。 |
| 软件配置管理 | SCM（Software Configuration Management） | 基线、变更控制相关活动。 |

## 术语裁剪指引

- 只收录正文实际出现的术语；「通用软件术语」一表按项目实际出现选用，不得为凑数整表照搬。
- 本文档为总结报告类，不出现 SRS 的"合格性方法/合格性级别"等验证术语；如第 4 章引用测试活动时涉及，以测试文档（STD/STR）中的定义为准。
- 单位名称、机构名称、人名一律不得写入术语或正文（第三方测评机构写"具备资质的第三方测评机构"，除非用户提供实名）。
