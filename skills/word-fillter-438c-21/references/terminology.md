# 军用软件文档常用术语表（[21] 计算机编程手册适用）

> 术语依据 GJB 438C-2021 及 [08]/[10]/[21] 模板正文用法整理。全文术语必须与本表保持一致；首次出现时用“中文全称（英文缩写）”格式。

## 配置管理与标识

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 计算机软件配置项 | CSCI（Computer Software Configuration Item） | 软件配置项，本文档所适用软件的标识对象，1.1 节标识。 |
| 基线 | Baseline | 经正式评审确认的文档/产品版本，后续更改受配置管理控制。 |
| 文档标识号 | — | 格式示例 `TN/x-DO-DS-V{N.xx}`，见 1.1 节。 |
| 项目唯一的标识符 | — | 接口、设备号、数据元素等的唯一编号，用于全项目追踪。 |

## 文档类型

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 计算机编程手册 | CPM（Computer Programming Manual） | [21] 本文档，描述目标计算机系统的编程环境。 |

| 软件开发计划 | SDP（Software Development Plan） | 引用文档之一。 |
| 接口设计说明 | IDD（Interface Design Description） | 接口设计信息可引用 IDD，4.3 条注明。 |
| 软件研制任务书 | — | 研制要求的任务来源文件。 |

## 编程环境相关（本文档核心）

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 宿主机 | Host Computer | 运行编辑程序、交叉编译程序的开发计算机，3.3 条。 |
| 目标机 / 目标计算机 | Target Computer | 软件最终运行和加载的计算机系统，全文核心对象。 |
| 交叉编译 | Cross Compilation | 在宿主机上生成目标机可执行代码的编译方式，3.3 条。 |
| 交叉编译程序 | Cross Compiler | 运行于宿主机、生成目标机代码的编译程序，3.3 条。 |
| 交叉汇编程序 | Cross Assembler | 运行于宿主机、生成目标机目标代码的汇编程序，3.3 条。 |
| 连接编辑程序 | Linkage Editor | 连接并定位程序映像的工具，3.3 条。 |
| 指令集体系结构 | ISA（Instruction Set Architecture） | 处理器指令的集合及其编程特征，4.1 条。 |
| 接口程序指令 | — | 软件系统对外提供的程序指令，4.2 条逐条描述。 |
| 外围设备 | Peripheral Device | 计算机系统中可编程控制的外部设备，4.3 条。 |
| 中断 | Interrupt | 处理器对异步事件的响应机制，3.2、4.1 条。 |
| 异常向量表 | Exception Vector Table | 异常/中断入口地址表，4.1 条中断处理。 |
| 程序映像 | Program Image | 编译连接后加载至目标计算机执行的完整程序代码，4.3 条。 |
| 看门狗定时器 | Watchdog Timer | 用于检测程序运行异常并自动复位的定时部件，3.2、4.6 条。 |

## 通用软件术语（非军用专属，按源码与实际配置出现选用）

> 纯软件、信息化项目正文中高频出现的通用术语。首次出现写“中文全称（英文缩写）”，此后用缩写；项目实际未出现的不得收录。

| 术语 | 英文/缩写 | 规范写法与使用场景 |
|------|-----------|----------------|
| 应用程序编程接口 | API（Application Programming Interface） | 对外接口的统称，接口程序指令语境。 |
| 联合测试行动组 | JTAG（Joint Test Action Group） | 目标机程序加载与调试的仿真接口，3.3、4.3 条。 |
| GNU 编译器套件 | GCC（GNU Compiler Collection） | 交叉编译工具链，3.3 条。 |

## 术语裁剪指引

- 裁剪原则：只收录正文实际出现的术语（与第 5 章 `generation_prompt` 的要求一致）；「通用软件术语」一表按项目实际出现选用，不得为凑数整表照搬。
- 本文档不含合格性方法、需求追踪等条目，相关术语（合格性方法、双向追踪、状态与方式等）一律不收。
- 通用术语与 GJB 术语定义冲突时，以本表 GJB 定义为准，正文避免混用。
