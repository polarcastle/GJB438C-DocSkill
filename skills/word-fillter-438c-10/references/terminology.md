# 军用软件文档常用术语表（[10] SDD 适用）

> 术语依据 GJB 438C-2021 及 [10] 模板正文用法整理。全文术语必须与本表保持一致；首次出现时用"中文全称（英文缩写）"格式。

## 配置管理与标识

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 计算机软件配置项 | CSCI（Computer Software Configuration Item） | SDD 第 4 章的划分单位，每个 CSCI 给一节（4.X）。 |
| 硬件配置项 | HWCI（Hardware Configuration Item） | 系统设计决策中涉及的硬件配置项，第 3 章 a）项。 |
| 计算机软件部件 | CSC（Computer Software Component） | CSCI 设计中的元素：主要分支、分支组成部分、类、对象、模块、函数、例程或数据库；可分层、可嵌套；与代码实体可以有一对一也可以没有对应关系。4.X.2 的对象。 |
| 计算机软件单元 | CSU（Computer Software Unit） | 可独立标识与追踪的软件元素，第 5 章追踪的一端。 |
| 项目唯一的标识符 | — | 软件部件、接口的唯一编号，4.X.2 a）和 4.X.4.1 强制要求。 |
| 程序库 | Library | 存放实现各部件的软件的场所，4.X.2 f）须指明。 |
| 基线 | Baseline | 经正式评审确认的版本，后续更改受控。 |
| 开发状态/类型 | — | 部件来源分类：新开发、按原样重用、再工程、为重用而开发，4.X.2 d）。 |

## 文档类型

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 软件概要设计说明 | SDD（Software Design Description） | [10] 本文档。 |
| 软件需求规格说明 | SRS（Software Requirements Specification） | 设计输入，第 3、5 章的决策来源与追踪目标。 |
| 接口设计说明 | IDD（Interface Design Description） | 接口设计信息可引用 IDD 代替详述（第 3 章 a）项）。 |
| 数据库设计说明 | DBDD（Data Base Design Description） | 数据库呈现设计可引用 DBDD（第 3 章 c）项）。 |
| 软件开发计划 | SDP（Software Development Plan） | 资源使用测量策划的引用出处（4.X.2 e））。 |

## 设计相关

| 术语 | 含义与使用场景 |
|------|----------------|
| 系统设计决策 | 系统行为设计决策＋影响软件部件选择与设计的决策，第 3 章。 |
| 设计约定 | 理解设计所需的命名、分层、接口风格等约定，第 3、4 章须给出或引用。 |
| 软件部件 | CSCI 设计的元素，4.X.2；可采用与设计方法学一致的名称（类、模块等）。 |
| 执行方案 | 部件间动态关系：控制流程、数据流、状态转换、时序、并发、例外处理等，4.X.3。 |
| 接口实体 | 参与接口的任何实体：软件部件、系统、配置项、用户等，4.X.4。 |
| 静态关系 / 动态关系 | 组成、调用、继承等结构关系 / 运行期相互作用关系，分别对应 4.X.2 b）与 4.X.3。 |
| 可追踪性 | 需求↔软件单元双向关联，第 5 章；与 SRS 章节号对应。 |

## 通用软件术语（非军用专属，按源码实际出现选用）

> 纯软件、信息化项目正文中高频出现的通用术语。首次出现写"中文全称（英文缩写）"，此后用缩写；源码中未出现的不得收录。

| 术语 | 英文/缩写 | 规范写法与使用场景 |
|------|-----------|----------------|
| 表述性状态转移 | REST（Representational State Transfer） | HTTP 资源接口风格；接口设计章节描述对外接口时使用。 |
| 远程过程调用 | RPC（Remote Procedure Call） | JSON-RPC 等远程调用协议的上位概念。 |
| JavaScript 对象表示法 | JSON（JavaScript Object Notation） | 数据交换格式；接口数据元素、消息体的默认格式。 |
| 超文本传输协议 | HTTP（Hypertext Transfer Protocol） | 接口通信协议；注明方法（GET/POST）、状态码。 |
| 应用程序编程接口 | API（Application Programming Interface） | 对外接口的统称。 |
| Java 开发工具包 | JDK（Java Development Kit） | 运行与构建环境需求（4.X.2 e）资源假设）。 |
| 软件配置管理 | SCM（Software Configuration Management） | 基线、变更控制相关活动。 |
| 程序库 | Repository / Library | 依赖仓库（如 Maven 仓库）与程序库的对应说明。 |

## 纯软件项目（无 HWCI）的术语裁剪指引

- 无硬件配置项（HWCI）的纯软件项目：正文不涉及硬件时，术语表不收 HWCI、物理兼容性等硬件相关术语；CSC/CSU 若正文未用作部件/单元划分也可不收，但 **CSCI、CSC（部件）与本文档类型（SDD）必须保留**。
- 裁剪原则：只收录正文实际出现的术语（与第 6 章 `generation_prompt` 的要求一致）；「通用软件术语」一表按源码实际出现选用，不得为凑数整表照搬。
- 通用术语与 GJB 术语定义冲突时（如"软件部件"在通用语境与 CSC 的定义不同），以本表 GJB 定义为准，正文避免混用。
