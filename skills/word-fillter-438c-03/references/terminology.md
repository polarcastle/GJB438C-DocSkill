# 军用软件文档常用术语表（[03] 软件配置管理计划适用）

> 术语依据 GJB 438C-2021 及 [03] 模板正文用法整理。全文术语必须与本表保持一致；首次出现时用"中文全称（英文缩写）"格式。

## 配置管理核心术语

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 软件配置管理 | SCM（Software Configuration Management） | 在软件生存周期内对软件配置项进行标识、控制、配置状态记实和配置审核的管理活动，本文档主题。 |
| 软件配置项 | SCI（Software Configuration Item） | 为配置管理而划分的、可独立标识和控制的软件工作产品（源代码、文档、数据等）。本文档"配置项"均指 SCI。 |
| 计算机软件配置项 | CSCI（Computer Software Configuration Item） | 军用标准语境下的软件配置项；与 SCI 同义时使用，全文统一。 |
| 基线 | Baseline | 经正式评审和同意、作为后续工作基础并只能经更改控制加以修改的软件配置项集合。本文档建立功能基线、分配基线、产品基线。 |
| 项目唯一的标识符 | — | 配置项、基线、接口等的唯一编号，用于全项目追踪；5.1 节标识方案的核心要求。 |
| 配置标识 | Configuration Identification | 确定配置项及其基线、并赋予唯一标识的活动，第 5.1 节。 |
| 配置控制 | Configuration Control | 对配置项和基线的更改进行申请、评审、批准和实施控制的活动，第 5.2 节。 |
| 配置状态记实 | Configuration Status Accounting | 记录并报告配置项状态信息的活动，第 5.3 节。 |
| 配置审核 | Configuration Audit | 验证配置项符合其规定需求的审核，第 5.4 节。 |
| 功能配置审核 | FCA（Functional Configuration Audit） | 验证配置项实际功能与其需求一致的审核。 |
| 物理配置审核 | PCA（Physical Configuration Audit） | 验证交付配置项的物理介质与文档一致的审核。 |
| 变更控制委员会 | CCB（Change Control Board） | 负责评审和批准更改申请的机构；本项目由项目负责人及部门配置管理组行使相应权限。 |

## "软件三库"术语（第 4 章专用）

| 术语 | 含义与使用场景 |
|------|----------------|
| 软件三库 | 开发库、受控库、产品库的统称，第 4 章管理对象。 |
| 开发库 | 存放项目开发过程中生成的所有软件配置项的软件库。 |
| 受控库 | 存放项目所有通过组织认可的测试或评审的软件配置项的软件库，实施变更控制。 |
| 产品库 | 存放供交付、生产、检验验收、维护的软件产品的软件库。 |
| 备份与恢复 | 定期复制三库内容并验证可恢复性的规程，第 4.4 节。 |

## 文档类型

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 软件配置管理计划 | SCMP（Software Configuration Management Plan） | [03] 本文档，规定项目的配置管理活动要求。 |
| 软件开发计划 | SDP（Software Development Plan） | 第 1.4、8 章：本计划的配置管理活动日程须与其保持一致。 |
| 软件质量保证计划 | SQAP（Software Quality Assurance Plan） | 第 1.4、8 章：配置审核与质量保证活动协同的依据。 |
| 软件研制任务书 | — | 交付要求等的任务来源文件，第 5.5 节 d）引用。 |
| 配置管理报告 | — | 配置管理员定期提交的状态报告，第 3 章职责表与 5.3 节 b）引用。 |

## 相关方与现场

| 术语 | 含义与使用场景 |
|------|----------------|
| 需方 / 用户 / 开发方 / 保障机构 | 项目的四类相关方，1.2 节标识；开发方常称"承研单位"。 |
| 供货单位 | 软件销售单位或软件分承制方，第 7 章控制对象。 |
| 运行现场 | 软件部署使用的地点/环境，区分当前（开发调试现场）和计划的（用户现场）。 |
| 项目负责人 / 配置管理员 | 项目级配置管理的关键角色，第 3 章职责表的两个必备角色。 |

## 裁剪指引

- 只收录正文实际出现的术语（与第 9 章 `generation_prompt` 的要求一致）；「通用软件术语」按源码和项目实际 toolchain 出现情况选用，不得为凑数整表照搬。
- 无硬件配置项（HWCI）的纯软件项目：正文不涉及硬件时不收 HWCI、CSC/CSU 等设计类术语；SCM、SCI、基线、三库、FCA/PCA 为本文档必备术语。
- 通用术语与 GJB 术语定义冲突时，以本表 GJB 定义为准，正文避免混用。
