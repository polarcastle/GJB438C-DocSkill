# 军用软件文档常用术语表（[31] 软件配置管理报告 适用）

> 术语依据 GJB 438C-2021 及 [31] 模板正文用法整理。全文术语必须与本表保持一致；首次出现时用"中文全称（英文缩写）"格式。

## 配置管理核心术语（本文档高频）

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 配置管理 | CM（Configuration Management） | 标识和控制配置项、管理变更、记录状态、审核完整性的活动集合，本文档的记述对象。 |
| 软件配置管理 | SCM（Software Configuration Management） | 软件产品的配置管理，[31] 报告期活动的主体。 |
| 配置项 | CI（Configuration Item） | 配置管理的基本单位：受控的文档、源代码、数据、工具等实体。第 6 章逐条列出。 |
| 基线 | Baseline | 经正式评审确认并作为后续工作基础的配置项集合，变更须审批。第 8 章。 |
| 功能基线 / 分配基线 / 产品基线 | — | 三类常用基线：分别对应需求、设计、产品交付状态；未建立时如实说明建立计划。 |
| 变更 | Change | 对已基线化配置项的修改申请及实施过程，第 7 章记录变更申请单号、时间、内容、申请人、批准人、实施人。 |
| 变更控制委员会 / 配置控制委员会 | CCB（Change Control Board） | 负责变更审批与基线发布的机构，第 4 章标识其组成。 |
| 配置库 | Repository / Library | 存储配置项及其版本的受控库，分开发区、测试区、受控区等；第 9/10 章的出入库对象。 |
| 入库 / 出库 | Check-in / Check-out | 配置项进入或离开受控配置库的活动，须填写入库单/出库单并审批。 |
| 配置审核 | CA（Configuration Audit） | 对配置项完整性、一致性和受控状态的检查，第 11 章记录不合格项及其关闭情况。 |
| 控制力度 | — | 配置项受控级别：基线管理、非基线管理（受到管理和控制），第 6 章逐项标注。 |
| 配置状态记录 | CSR（Configuration Status Report） | 记录配置项当前状态、变更实施情况的报告，第 13 章"配置状态记录份数"的统计对象。 |
| 不合格项 | Nonconformance Item | 审核中发现的不符合规程的问题项，须记录数量与关闭情况。 |

## 配置管理与标识

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 计算机软件配置项 | CSCI（Computer Software Configuration Item） | 软件配置项的军用称谓，正文中作为源代码类配置项时使用。 |
| 文档标识号 | — | 格式示例 `TN/x-DO-DS-V{N.xx}`，见 1.1 节，与封面、页眉保持一致。 |
| 项目唯一的标识符 | — | 变更单号（BG-YYYY-NNN）、入库单号（RK-YYYY-NNN）、出库单号（CK-YYYY-NNN）、审核单号（SH-YYYY-NNN）等单据编号。 |

## 文档类型

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 软件配置管理报告 | CMR（Configuration Management Report） | [31] 本文档，按报告期汇总配置管理活动情况。 |
| 软件配置管理计划 | SCMP（Software Configuration Management Plan） | 配置管理活动的策划文档，第 3 章偏差对比的基准。 |
| 软件需求规格说明 | SRS（Software Requirements Specification） | 通常作为功能基线内容的文档。 |
| 软件开发计划 | SDP（Software Development Plan） | 项目管理类文档，常作为非基线管理配置项。 |
| 软件研制任务书 | — | 任务来源文件。 |

## 通用软件术语（按项目实际出现选用）

> 首次出现写"中文全称（英文缩写）"，此后用缩写；项目中未出现的不得收录。

| 术语 | 英文/缩写 | 规范写法与使用场景 |
|------|-----------|----------------|
| 应用程序编程接口 | API（Application Programming Interface） | 对外接口的统称，出现在配置项功能描述中时使用。 |
| 源代码 | Source Code | 受控配置项的主要类别。 |
| 版本 / 发布号 | Version / Release | 配置项与基线的版本标识，格式统一（如 V1.0、Release 1）。 |
