# 军用软件文档常用术语表（[20] 软件用户手册适用）

> 术语依据 GJB 438C-2021 及 [20] 模板正文用法整理。全文术语必须与本表保持一致；首次出现时用"中文全称（英文缩写）"格式。

## 配置管理与标识

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 计算机软件配置项 | CSCI（Computer Software Configuration Item） | 软件配置项，研制文档与验收的基本对象。用户手册通常以整个 CSCI 为描述对象。 |
| 硬件配置项 | HWCI（Hardware Configuration Item） | 与 CSCI 对应的硬件配置项；手册中涉及硬件设备需求时可提及。 |
| 项目唯一的标识符 | — | 软件、文档、消息编号等的唯一编号，用于全项目追踪。手册中的消息编号（如 E-1001）应保持唯一且规则一致。 |
| 基线 | Baseline | 经正式评审确认的文档/产品版本，后续更改受配置管理控制。手册版本应与软件基线版本对应。 |
| 文档标识号 | — | 格式示例 `TN/x-DO-DS-V{N.xx}`，见 1.1 节。 |

## 文档类型

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 软件用户手册 | SUM（Software User Manual） | [20] 本文档，向用户提供软件使用规程。 |
| 软件需求规格说明 | SRS（Software Requirements Specification） | [08]，软件功能的依据文档，手册中可引用。 |
| 软件概要设计说明 | SDD（Software Design Description） | [10]，软件结构设计的依据文档，手册中可引用。 |
| 接口需求规格说明 | IRS（Interface Requirements Specification） | 接口需求文档，手册描述与外部系统交互时可引用。 |
| 软件研制任务书 | — | 软件研制任务的来源文件。 |

## 用户手册专用术语

| 术语 | 含义与使用场景 |
|------|----------------|
| 运行现场 | 软件部署使用的地点/环境，区分当前和计划的（1.2 节标识）。 |
| 逻辑部件 | 从用户角度看到的软件组成部分（3.4 节），不必与代码模块一一对应。 |
| 降级（紧急模式） | 部分功能停用、仅保留核心能力的运行状态（3.5 节）。 |
| 处理规程 | 完成某项使用方面（功能/菜单/事务）的操作步骤（5.3 节）。 |
| 批处理 / 后台处理 | 未被用户直接调用、由软件自动执行的处理（5.4 节）。 |
| 备份与恢复 | 数据副本的创建、保留与用于恢复的操作（5.5、5.6 节）。 |
| 快速参考卡 | 常用功能键、控制序列、命令的速查表（5.8 节）。 |
| 需方 / 用户 / 开发方 / 保障机构 | 项目的四类相关方：需求提出方、软件使用者、研制方、维护保障组织（1.2 节标识）。 |

## 通用软件术语（非军用专属，按软件实际出现选用）

> 纯软件、信息化项目正文中高频出现的通用术语。首次出现写"中文全称（英文缩写）"，此后用缩写；软件中未出现的不得收录。

| 术语 | 英文/缩写 | 规范写法与使用场景 |
|------|-----------|----------------|
| JavaScript 对象表示法 | JSON（JavaScript Object Notation） | 配置文件、数据交换格式；手册中描述配置文件格式时使用。 |
| 超文本传输协议 | HTTP（Hypertext Transfer Protocol） | 软件提供 Web 界面或接口时注明。 |
| 应用程序编程接口 | API（Application Programming Interface） | 对外接口的统称。 |
| 命令行界面 | CLI（Command-Line Interface） | 软件以命令行方式操作时描述启动参数、命令。 |
| 图形用户界面 | GUI（Graphical User Interface） | 软件以窗口界面操作时描述菜单、按钮、对话框。 |
| 数据库 | DB（Data Base） | 软件使用数据库时描述数据文件与备份（3.2、5.5 节）。 |
| 平均故障间隔时间 | MTBF（Mean Time Between Failures） | 可靠性量化指标（3.4 b）7））。 |
| 客户机/服务器 | C/S（Client/Server） | 软件架构描述（1.2 节）。 |

## 术语裁剪指引

- 只收录正文实际出现的术语（与第 6 章 `generation_prompt` 的要求一致）；「通用软件术语」一表按软件实际出现选用，不得为凑数整表照搬。
- 无硬件配置项（HWCI）的纯软件项目：正文不涉及硬件时，术语表不收 HWCI 等硬件/机电相关术语。
- 通用术语与 GJB 术语定义冲突时，以本表 GJB 定义为准，正文避免混用。
