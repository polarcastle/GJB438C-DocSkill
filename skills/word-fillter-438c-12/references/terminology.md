# 军用软件文档常用术语表（[12] 软件详细设计说明适用）

> 术语依据 GJB 438C-2021 及 [12] 模板正文用法整理。全文术语必须与本表保持一致；首次出现时用"中文全称（英文缩写）"格式。

## 配置管理与标识

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 计算机软件配置项 | CSCI（Computer Software Configuration Item） | 软件配置项，需求、设计、实现与测试的基本对象。本文档对每个软件单元给出到 CSCI 需求的可追踪性（第 4 章）。 |
| 硬件配置项 | HWCI（Hardware Configuration Item） | 与 CSCI 对应的硬件配置项；纯软件项目正文不涉及时可不收。 |
| 计算机软件部件 | CSC（Computer Software Component） | CSCI 设计中的元素：类、对象、模块、函数、例程或数据库；概要设计的分解对象。 |
| 计算机软件单元 | CSU（Computer Software Unit） | CSCI 设计中可单独测试的最小软件元素，**本文档第 3 章的说明对象**，以项目唯一的标识符（如 SU-01）标识。 |
| 项目唯一的标识符 | — | 接口、数据元素、软件单元等的唯一编号，用于全项目追踪。本文档每个软件单元必须给出。 |
| 基线 | Baseline | 经正式评审确认的文档/产品版本，后续更改受配置管理控制。 |
| 文档标识号 | — | 格式示例 `TN/x-DO-DS-V{N.xx}`，见 1.1 节与封面。 |

## 文档类型

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 软件详细设计说明 | SDD（Software Design Description） | [12] 本文档（详细设计层）；注意与 [10] 概要设计说明同名缩写，引用时注明版本/层次。 |
| 软件需求规格说明 | SRS（Software Requirements Specification） | 需求的出处，第 4 章可追踪性的目标文档。 |
| 软件概要设计说明 | SDD（Software Design Description） | [10] 概要设计文档，本文档的设计依据，1.2/第 2 章引用。 |
| 接口设计说明 | IDD（Interface Design Description） | 软件单元接口特性可引用 IDD 代替详述（第 3 章 e）项注明）。 |
| 数据库设计说明 | DBDD（Data Base Design Description） | 软件单元为数据库时应引用 DBDD（第 3 章 e）项注明）。 |
| 软件开发计划 | SDP（Software Development Plan） | 项目计划类文档，引用时注明。 |

## 追踪与设计相关

| 术语 | 含义与使用场景 |
|------|----------------|
| 双向追踪 | 正向（软件单元→CSCI 需求）与逆向（CSCI 需求→软件单元）追踪，本文档第 4 章的 a）b）两条。 |
| 需方 / 用户 / 开发方 / 保障机构 | 项目的四类相关方，1.2 节标识。 |
| 运行现场 | 软件部署使用的地点/环境，区分当前和计划的，1.2 节标识。 |
| 数据元素 / 数据元素组合体 | 软件单元输入、输出及内部数据的描述单位，第 3 章 e）项；局部数据应与输入输出数据分开描述。 |
| 过程性命令 | 菜单选择、在线 DBMS 查询、GUI 构造器输入、操作系统命令或 Shell 脚本等非代码形式的命令，第 3 章 d）项，无则如实陈述。 |
| 单元设计决策 | 软件单元所用的算法、数据结构等设计选择，第 3 章 a）项；此前未选定的算法必须在详细设计中给出。 |
| 动态控制序列 | 软件单元运行期间的操作顺序、时序关系、中断处理等行为，第 3 章 f）项。 |

## 通用软件术语（非军用专属，按源码实际出现选用）

> 纯软件、信息化项目正文中高频出现的通用术语。首次出现写"中文全称（英文缩写）"，此后用缩写；源码中未出现的不得收录。

| 术语 | 英文/缩写 | 规范写法与使用场景 |
|------|-----------|----------------|
| JavaScript 对象表示法 | JSON（JavaScript Object Notation） | 数据交换格式；接口数据元素、消息体的默认格式。 |
| 超文本传输协议 | HTTP（Hypertext Transfer Protocol） | 接口通信协议；注明方法（GET/POST）、状态码。 |
| 应用程序编程接口 | API（Application Programming Interface） | 对外接口的统称。 |
| 数据库管理系统 | DBMS（Data Base Management System） | 涉及数据库的单元引用 DBDD 时使用。 |
| 图形用户界面 | GUI（Graphical User Interface） | 过程性命令（GUI 构造器输入）场景使用。 |
| 软件配置管理 | SCM（Software Configuration Management） | 基线、变更控制相关活动。 |

## 纯软件项目（无 HWCI）的术语裁剪指引

- 无硬件配置项（HWCI）的纯软件项目：正文不涉及硬件时，术语表不收 HWCI、物理兼容性等硬件/机电相关术语。
- 裁剪原则：只收录正文实际出现的术语（与第 5 章 `generation_prompt` 的要求一致）；「通用软件术语」一表按源码实际出现选用，不得为凑数整表照搬。
- **CSCI、CSU 与本文档类型（SDD）必须保留**；概要设计层术语（CSC）在引用《软件概要设计说明》时保留。
- 通用术语与 GJB 术语定义冲突时，以本表 GJB 定义为准，正文避免混用。
