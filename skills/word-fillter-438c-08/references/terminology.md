# 军用软件文档常用术语表（[08] SRS 适用）

> 术语依据 GJB 438C-2021 及 [08]/[10] 模板正文用法整理。全文术语必须与本表保持一致；首次出现时用"中文全称（英文缩写）"格式。

## 配置管理与标识

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 计算机软件配置项 | CSCI（Computer Software Configuration Item） | 软件配置项，需求、设计、测试文档的基本对象。SRS 中的"合格性方法 A-演示"以 CSCI 或其一部分为对象。 |
| 硬件配置项 | HWCI（Hardware Configuration Item） | 与 CSCI 对应的硬件配置项；SDD 中系统设计决策涉及与 HWCI 的接口。 |
| 计算机软件部件 | CSC（Computer Software Component） | CSCI 设计中的元素：类、对象、模块、函数、例程或数据库；可出现在层次结构不同层上，可由其他部件组成。 |
| 计算机软件单元 | CSU（Computer Software Unit） | CSCI 设计中可单独测试的最小软件元素；SDD 第 5 章追踪的对象。 |
| 项目唯一的标识符 | — | 接口、数据元素、需求等的唯一编号，用于全项目追踪。SRS 每个接口和数据元素都必须给出。 |
| 基线 | Baseline | 经正式评审确认的文档/产品版本，后续更改受配置管理控制。 |
| 文档标识号 | — | 格式示例 `TN/x-DO-DS-V{N.xx}`，见 1.1 节。 |

## 文档类型

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 软件需求规格说明 | SRS（Software Requirements Specification） | [08] 本文档。 |
| 接口需求规格说明 | RS（Interface Requirements Specification） | 接口需求可引用它代替详述，SRS 3.3 条注明。 |
| 软件概要设计说明 | SDD（Software Design Description） | [10] 概要设计文档。 |
| 接口设计说明 | IDD（Interface Design Description） | 接口设计信息可引用 IDD 代替详述，SDD 第 3 章注明。 |
| 数据库设计说明 | DBDD（Data Base Design Description） | 数据库呈现设计可引用 DBDD，SDD 第 3 章注明。 |
| 软件开发计划 | SDP（Software Development Plan） | 资源使用测量策划的出处，SDD 4.X.2 e）引用。 |
| 软件研制任务书 | — | 质量因素、验收要求的任务来源文件。 |

## 合格性（SRS 第 4 章专用）

| 术语 | 含义与使用场景 |
|------|----------------|
| 合格性方法 | 验证需求满足程度的方法，五选一：A-演示、B-测试、C-分析、D-检查、E-特殊方法。 |
| ├ 演示 | 对 CSCI（或部分 CSCI）进行直接可观察的功能操作，不需要复杂或专用的测试设备。 |
| ├ 测试 | 通过测试设备或测试程序验证。 |
| ├ 分析 | 通过建模、仿真、推理等手段验证。 |
| ├ 检查 | 对 CSCI 的编码、文档等进行直观检查。 |
| └ 特殊方法 | 专用工具、技术、过程、设施、验收限制。 |
| 合格性级别 | 问题发现时机，四选一：a-配置项（CSCI 内）；b-系统集成时；c-系统；d-系统安装时。 |

## 需求相关

| 术语 | 含义与使用场景 |
|------|----------------|
| 能力 | 一组相关需求，可按功能、主题、对象划分，SRS 3.2 的组成单位。 |
| 状态与方式 | 软件运行条件类别（空闲、就绪、活动、事后分析、训练、降级、紧急情况、后备、战时/平时等），SRS 3.1 定义。 |
| 降级 | 部分功能失效时降低能力继续运行的状态。 |
| 双向追踪 | 正向（来源指标→需求）与逆向（需求→来源指标）追踪，SRS 第 5 章。 |
| 需方 / 开发方 / 保障机构 | 项目的三类相关方：需求提出方、软件开发方、维护保障组织，1.2 节标识。 |
| 运行现场 | 软件部署使用的地点/环境，区分当前和计划的。 |
| 人素工程 | 考虑人的能力和局限性、可预见人为错误的工程设计，SRS 3.13。 |
| 适应性 | 软件随安装场地或运行参数变化而调整的能力，SRS 3.6。 |

## 通用软件术语（非军用专属，按源码实际出现选用）

> 纯软件、信息化项目正文中高频出现的通用术语。首次出现写"中文全称（英文缩写）"，此后用缩写；源码中未出现的不得收录。

| 术语 | 英文/缩写 | 规范写法与使用场景 |
|------|-----------|----------------|
| 表述性状态转移 | REST（Representational State Transfer） | HTTP 资源接口风格；写接口类型时使用，如"REST 接口"。 |
| 远程过程调用 | RPC（Remote Procedure Call） | JSON-RPC 等远程调用协议的上位概念。 |
| JavaScript 对象表示法 | JSON（JavaScript Object Notation） | 数据交换格式；接口数据元素、消息体的默认格式。 |
| 超文本传输协议 | HTTP（Hypertext Transfer Protocol） | 接口通信协议；注明方法（GET/POST）、状态码。 |
| 应用程序编程接口 | API（Application Programming Interface） | 对外接口的统称。 |
| Java 开发工具包 | JDK（Java Development Kit） | 运行与构建环境需求（3.9、3.10.3）。 |
| 模型上下文协议 | MCP（Model Context Protocol） | 仅当源码实现该协议时收录（如 MCP 服务端点）。 |
| 软件配置管理 | SCM（Software Configuration Management） | 基线、变更控制相关活动。 |

## 纯软件项目（无 HWCI）的术语裁剪指引

- 无硬件配置项（HWCI）的纯软件项目：正文不涉及硬件时，术语表不收 HWCI、物理兼容性、人素工程等硬件/机电相关术语；CSC/CSU 若正文未用作部件/单元划分（如规模小、只以 CSCI 为对象）也可不收，但 **CSCI 与本文档类型（SRS）必须保留**。
- 裁剪原则：只收录正文实际出现的术语（与第 6 章 `generation_prompt` 的要求一致）；「通用软件术语」一表按源码实际出现选用，不得为凑数整表照搬。
- 通用术语与 GJB 术语定义冲突时（如"软件单元"在通用语境与 CSU 的定义不同），以本表 GJB 定义为准，正文避免混用。 |
