# 军用软件文档常用术语表（[22] 测试问题报告适用）

> 术语依据 GJB 438C-2021 及 [22] 模板正文用法整理。全文术语必须与本表保持一致；首次出现时用"中文全称（英文缩写）"格式。

## 配置管理与标识

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 计算机软件配置项 | CSCI（Computer Software Configuration Item） | 软件配置项，测试对象为 CSCI 或其一部分。 |
| 硬件配置项 | HWCI（Hardware Configuration Item） | 与 CSCI 对应的硬件配置项；纯软件项目正文不涉及。 |
| 项目唯一的标识符 | — | 测试用例、问题报告单的唯一编号，用于全项目追踪。 |
| 基线 | Baseline | 经正式评审确认的文档/产品版本，测试依据文档须注明基线版本。 |
| 文档标识号 | — | 格式示例 `TN/x-DO-DS-V{N.xx}`，见 1.1 节。 |
| 回归测试 | Regression Testing | 问题修改后重新执行的测试，问题状态（发现/关闭/返回/暂缓/通过）以回归测试结果为判定依据。 |

## 文档类型

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 测试问题报告 | — | [22] 本文档，记录软件测试过程中发现的问题及其统计。 |
| 软件测试计划 | STP（Software Test Plan） | 测试活动的策划文档，常列为测评依据。 |
| 软件测试说明 | STD（Software Test Description） | 测试用例与测试规程的说明文档，问题单中的"测试用例名称/标识"出自该文档。 |
| 软件测试报告 | STR（Software Test Report） | 测试执行结果的综合报告，与本报告配套。 |
| 软件需求规格说明 | SRS（Software Requirements Specification） | 问题判定的需求依据，测评依据表中列出。 |
| 软件研制任务书 | — | 测试验收要求的任务来源文件。 |

## 问题管理（[22] 第 3 章模板标准定义）

| 术语 | 含义与使用场景 |
|------|----------------|
| 问题类型 | 四类：功能错误（已实现但实现错误）、功能缺失（未实现要求功能）、界面问题（功能正确但交互界面不规范/提示信息有误）、其他（无法计入以上三类）。 |
| 问题等级 | 四级：致命问题（系统崩溃、异常退出、数据丢失且很难恢复）、严重问题（未实现/未正确实现需求且影响较大、数据丢失但较易恢复）、一般问题（未实现/未正确实现需求但影响较小、操作与使用说明不符）、建议改进（易用性等影响轻微的问题）。 |
| 问题状态 | 五类：发现（回归测试中新发现）、关闭（经沟通确认不属于问题）、返回（研制方已修改但回归测试仍出现）、暂缓（研制方原因延迟至以后版本）、通过（回归测试确认已修复）。 |
| 测评依据 | 第 2 章表格所列测试依据文档（需求规格说明、测试计划、标准规范等）的统称。 |

## 通用软件术语（非军用专属，按源码实际出现选用）

> 纯软件、信息化项目正文中高频出现的通用术语。首次出现写"中文全称（英文缩写）"，此后用缩写；源码中未出现的不得收录。

| 术语 | 英文/缩写 | 规范写法与使用场景 |
|------|-----------|----------------|
| 超文本传输协议 | HTTP（Hypertext Transfer Protocol） | 被测软件为服务接口时，描述测试接口所用协议。 |
| 应用程序编程接口 | API（Application Programming Interface） | 被测对外接口的统称。 |
| 数据库 | DB（Data Base） | 被测软件涉及数据存储时，问题单中数据丢失类问题的对象。 |
| 软件配置管理 | SCM（Software Configuration Management） | 问题报告单、测评依据文档的归档与变更控制。 |

## 纯软件项目（无 HWCI）的术语裁剪指引

- 无硬件配置项（HWCI）的纯软件项目：正文不涉及硬件时，术语表不收 HWCI 等硬件/机电相关术语；**CSCI 与本文档类型（测试问题报告）必须保留**。
- 裁剪原则：只收录正文实际出现的术语（与 `references/terminology.md` 的使用要求一致）；「通用软件术语」一表按源码实际出现选用，不得为凑数整表照搬。
- 通用术语与 GJB 术语定义冲突时，以本表 GJB 定义为准，正文避免混用。
