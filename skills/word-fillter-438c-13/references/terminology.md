# 军用软件文档常用术语表（[13] IDD 适用）

> 术语依据 GJB 438C-2021 及 [13] 模板正文用法整理。全文术语必须与本表保持一致；首次出现时用"中文全称（英文缩写）"格式。

## 配置管理与标识

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 计算机软件配置项 | CSCI（Computer Software Configuration Item） | 软件配置项，接口设计的基本对象；本文档描述的接口隶属于某个 CSCI。 |
| 硬件配置项 | HWCI（Hardware Configuration Item） | 与 CSCI 对应的硬件配置项；接口实体可能是 HWCI 时注明。 |
| 计算机软件部件 | CSC（Computer Software Component） | CSCI 设计中的元素：类、对象、模块、函数、例程或数据库。 |
| 计算机软件单元 | CSU（Computer Software Unit） | CSCI 设计中可单独测试的最小软件元素。 |
| 项目唯一的标识符 | — | 接口、数据元素、数据元素集合体等的唯一编号，用于全项目追踪。IDD 每个接口和数据元素都必须给出。 |
| 接口实体 | Interface Entity | 共享、提供或交换数据的系统、配置项、用户或其他实体；第 3 章从接口实体角度描述特性。 |
| 基线 | Baseline | 经正式评审确认的文档/产品版本，后续更改受配置管理控制。 |
| 文档标识号 | — | 格式示例 `TN/x-DO-DS-V{N.xx}`，见 1.1 节。 |

## 文档类型

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 接口设计说明 | IDD（Interface Design Description） | [13] 本文档，描述软件接口的设计特性。 |
| 接口需求规格说明 | RS（Interface Requirements Specification） | 接口需求出处文件，IDD 的追踪来源（第 4 章）。 |
| 软件需求规格说明 | SRS（Software Requirements Specification） | [08] 需求文档，IDD 第 4 章可追踪到其中的需求条目。 |
| 软件概要设计说明 | SDD（Software Design Description） | [10] 概要设计文档，与 IDD 配套使用。 |
| 数据字典 | Data Dictionary | 可引用代替数据元素详述（第 3.2 节注明）。 |
| 协议标准 / 用户接口标准 | — | 可引用代替通信方法与协议特性的详述（第 3.2 节注明）。 |
| 软件研制任务书 | — | 接口设计约束的任务来源文件。 |

## 接口特性相关（第 3.2 节 a）～g）组织单位）

| 术语 | 含义与使用场景 |
|------|----------------|
| 数据元素 | 接口中必须提供、存储、发送、访问或接收的最小数据单位；特性含 9 项（名称/标识符、数据类型、大小和格式、计量单位、取值范围或枚举、准确度和精度、约束条件、保密性约束、来源和接收者）。 |
| 数据元素集合体 | 由若干数据元素按结构组合而成的记录、消息、文件、显示或报表；特性含 8 项。 |
| 通信方法 | 接口使用的链接/带宽/频率/媒体、消息格式化、流控制、数据传送速率、路由寻址命名约定、传输服务、安全保密考虑。 |
| 协议 | 接口使用的协议优先级别/层次、打包、合法性检查/错误控制/恢复、同步、状态标识报告。 |
| 物理兼容性 | 尺寸、公差、负荷、电压和接插件兼容性等；纯软件项目通常写"无"。 |
| 假设陈述 | 对未在本文档涵盖的接口实体，其特性以"当[未涵盖的实体]这样做时，[所指定的实体]将……"形式描述，不得对该实体提需求。 |

## 通用软件术语（非军用专属，按源码实际出现选用）

> 纯软件、信息化项目正文中高频出现的通用术语。首次出现写"中文全称（英文缩写）"，此后用缩写；源码中未出现的不得收录。

| 术语 | 英文/缩写 | 规范写法与使用场景 |
|------|-----------|----------------|
| 表述性状态转移 | REST（Representational State Transfer） | HTTP 资源接口风格；写接口类型时使用，如"REST 接口"。 |
| 远程过程调用 | RPC（Remote Procedure Call） | JSON-RPC 等远程调用协议的上位概念。 |
| JavaScript 对象表示法 | JSON（JavaScript Object Notation） | 数据交换格式；接口数据元素、消息体的默认格式。 |
| 超文本传输协议 | HTTP（Hypertext Transfer Protocol） | 接口通信协议；注明方法（GET/POST）、状态码。 |
| 应用程序编程接口 | API（Application Programming Interface） | 对外接口的统称。 |
| 传输控制协议 | TCP（Transmission Control Protocol） | 通信方法特性中注明传输层协议。 |
| 软件配置管理 | SCM（Software Configuration Management） | 基线、变更控制相关活动。 |

## 纯软件项目（无 HWCI）的术语裁剪指引

- 无硬件配置项（HWCI）的纯软件项目：正文不涉及硬件时，术语表不收 HWCI、物理兼容性等硬件/机电相关术语；CSC/CSU 若正文未用作部件/单元划分也可不收，但 **CSCI、IDD、接口实体、项目唯一标识符、数据元素必须保留**。
- 裁剪原则：只收录正文实际出现的术语（与第 5 章 `generation_prompt` 的要求一致）；「通用软件术语」一表按源码实际出现选用，不得为凑数整表照搬。
- 通用术语与 GJB 术语定义冲突时，以本表 GJB 定义为准，正文避免混用。
