# 军用软件文档常用术语表（[28] 研制总结报告适用）

> 术语依据 GJB 438C-2021 及 [28] 模板正文用法整理。全文术语必须与本表保持一致；首次出现时用"中文全称（英文缩写）"格式。

## 配置管理与标识

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 计算机软件配置项 | CSCI（Computer Software Configuration Item） | 软件配置管理的基本单元；本文档第 3 章用于说明软件内部配置项构成关系。 |
| 项目唯一的标识符 | — | 软件、文档、接口等的唯一编号，用于全项目标识。 |
| 基线 | Baseline | 经正式评审确认的配置项版本，后续更改受配置管理控制；分功能基线、分配基线、产品基线。 |
| 功能基线 | Functional Baseline | 经批准的系统/软件功能描述，作为功能更改控制的基准。 |
| 分配基线 | Allocated Baseline | 分配到各配置项的需求基线，作为配置项研制依据。 |
| 产品基线 | Product Baseline | 研制结束时经确认的成品配置项集合，作为交付和验收的依据。 |
| 文档标识号 | — | 见 1.1 标识节，格式由项目文档管理规定确定。 |
| 配置状态报告 | — | 记录配置项版本、变更和基线状态的报告，第 9 章引用。 |

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 研制总结报告 | — | [28] 本文档，总结软件研制全过程、指标满足情况和研制成果评价。 |

| 软件配置管理报告 | — | [31] 文档，配置管理情况的总结，第 6、9 章引用。 |

## 研制过程与质量

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| GJB2786A | — | 军用软件研制过程要求标准，第 4 章研制过程概述引用。 |
| 系统联试 | — | 软件随系统开展的联合调试与测试活动，第 4、8 章引用。 |
| 试验考核 | — | 随所属设备或系统参加的正式试验，第 4、8 章引用。 |
| 软件测评 | — | 由测评机构对软件进行的独立测试与评估，第 5、8 章引用。 |
| 需方 / 开发方 / 分承制 / 保障机构 | — | 项目的四类相关方：任务提出与验收方、软件开发方、承担部分研制任务的单位、维护保障组织。 |
| 运行现场 | — | 软件部署使用的地点/环境，区分当前和计划的，第 1.2 节标识。 |
| 平均故障间隔时间 | MTBF（Mean Time Between Failures） | 可靠性指标，相邻两次故障之间的平均工作时间，第 5、11 章引用。 |
| 缺陷密度 | — | 单位代码规模中的缺陷数量（个/千行），第 10 章产品质量引用。 |
| 问题归零 | — | 质量问题按"定位准确、机理清楚、措施有效、举一反三"闭环处理，第 8 章引用。 |
| 软件关键性等级 | — | 按软件失效影响确定的关键程度等级（如关键、重要、一般），第 3 章引用。 |
| 代码规模 | — | 软件源代码行数规模，第 3、6、10 章引用。 |

## 通用软件术语（非军用专属，按项目实际出现选用）

> 纯软件、信息化项目正文中高频出现的通用术语。首次出现写"中文全称（英文缩写）"，此后用缩写；项目实际未出现的不得收录。

| 术语 | 英文/缩写 | 规范写法与使用场景 |
|------|-----------|----------------|
| 应用程序编程接口 | API（Application Programming Interface） | 对外接口的统称。 |
| JavaScript 对象表示法 | JSON（JavaScript Object Notation） | 数据交换格式；接口数据、消息体的默认格式。 |
| 超文本传输协议 | HTTP（Hypertext Transfer Protocol） | 接口通信协议；注明方法（GET/POST）、状态码。 |
| 实时操作系统 | RTOS（Real-Time Operating System） | 软件运行平台，第 3 章引用。 |
| 软件配置管理 | SCM（Software Configuration Management） | 基线、变更控制相关活动，第 9 章。 |

## 裁剪指引

- 只收录正文实际出现的术语（与第 13 章内容要求一致）；「通用软件术语」一表按项目实际出现选用，不得为凑数整表照搬。
- 通用术语与 GJB 术语定义冲突时，以本表 GJB 定义为准，正文避免混用。
- 无硬件配置项（HWCI）的纯软件项目：正文不涉及硬件时术语表不收 HWCI 等硬件相关术语。
