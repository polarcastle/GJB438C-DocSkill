# 军用软件文档常用术语表（[29] 技术总结报告适用）

> 术语依据 GJB 438C-2021 及 [08]/[10]/[29] 模板正文用法整理。全文术语必须与本表保持一致；首次出现时用"中文全称（英文缩写）"格式。

## 配置管理与标识

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 计算机软件配置项 | CSCI（Computer Software Configuration Item） | 软件配置项，研制、总结的基本对象；本文档总结的对象即一个或多个 CSCI。 |
| 计算机软件部件 | CSC（Computer Software Component） | CSCI 设计中的元素：类、对象、模块、函数、例程或数据库；技术实现途径中描述其研制与集成情况。 |
| 计算机软件单元 | CSU（Computer Software Unit） | CSCI 设计中可单独测试的最小软件元素；总结测试覆盖情况时引用。 |
| 硬件配置项 | HWCI（Hardware Configuration Item） | 与 CSCI 对应的硬件配置项；纯软件项目正文不涉及时可不收该术语。 |
| 项目唯一的标识符 | — | 接口、数据元素、需求等的唯一编号；总结中引用需求、接口时使用原文标识，不得自造新号。 |
| 基线 | Baseline | 经正式评审确认的文档/产品版本；技术总结应说明软件达到的基线状态。 |
| 文档标识号 | — | 本项目文档编号规则见 `config.json` 的 `document.id` 示例。 |
| 研制任务书 | — | 任务来源与考核指标的依据文件，1.1/1.2 节引用。 |

## 文档类型

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 软件需求规格说明 | SRS（Software Requirements Specification） | [08] 需求文档；技术总结中对比"指标要求 vs 实现情况"时引用。 |
| 软件概要设计说明 | SDD（Software Design Description） | [10] 概要设计文档；总体设计小节内容的出处。 |
| 软件详细设计说明 | — | 部件级设计文档；技术实现途径中可引用。 |
| 软件测试计划/测试说明 | STP/STD（Software Test Plan/Description） | 测试类文档；总结验证情况时引用。 |
| 软件配置管理计划 | SCMP（Software Configuration Management Plan） | 配置管理活动依据；更改记录表的管理出处。 |
| 软件开发计划 | SDP（Software Development Plan） | 研制过程对比的计划基线。 |

## 总结报告常用表述

| 术语 | 含义与使用场景 |
|------|----------------|
| 任务来源 | 说明项目下达的途径与依据文件（研制任务书、合同、协议等），1.1 节使用。 |
| 考核指标 | 任务书中规定、需在总结中逐项给出实现结论的技术指标，3.1 节使用。 |
| 实现途径 | 为达到指标所采用的技术路线、方案选型和工程方法，第 4 章使用。 |
| 关键技术 | 研制中起决定作用、需要突破的技术点，5.1 节使用；应写清"难在何处、如何解决"。 |
| 创新点 | 相对于以往型号或同类技术的改进与首创，5.2 节使用；应有对比对象和证据。 |
| 指标符合性 | 实现值与任务书要求值的对比结论（满足/不满足及偏差），3.1 节逐项给出。 |

## 通用软件术语（非军用专属，按源码实际出现选用）

> 纯软件、信息化项目正文中高频出现的通用术语。首次出现写"中文全称（英文缩写）"，此后用缩写；源码中未出现的不得收录。

| 术语 | 英文/缩写 | 规范写法与使用场景 |
|------|-----------|----------------|
| 表述性状态转移 | REST（Representational State Transfer） | HTTP 资源接口风格；写接口设计时使用，如"REST 接口"。 |
| 远程过程调用 | RPC（Remote Procedure Call） | 远程调用协议的上位概念。 |
| JavaScript 对象表示法 | JSON（JavaScript Object Notation） | 数据交换格式；接口数据、消息体的默认格式。 |
| 超文本传输协议 | HTTP（HyperText Transfer Protocol） | 接口通信协议；注明方法（GET/POST）、状态码。 |
| 应用程序编程接口 | API（Application Programming Interface） | 对外接口的统称。 |
| 软件配置管理 | SCM（Software Configuration Management） | 基线、变更控制相关活动。 |
| 平均故障间隔时间 | MTBF（Mean Time Between Failures） | 可靠性指标的常用量化表述，3.1.2 节使用。 |

## 纯软件项目（无 HWCI）的术语裁剪指引

- 无硬件配置项（HWCI）的纯软件项目：正文不涉及硬件时，术语表不收 HWCI 等硬件/机电相关术语；CSC/CSU 若正文未用作部件/单元划分（如规模小、只以 CSCI 为对象）也可不收，但 **CSCI 与本文档类型（技术总结报告）必须保留**。
- 裁剪原则：只收录正文实际出现的术语；「通用软件术语」一表按源码实际出现选用，不得为凑数整表照搬。
- 通用术语与 GJB 术语定义冲突时，以本表 GJB 定义为准，正文避免混用。
