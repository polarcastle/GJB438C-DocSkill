# 军用软件文档常用术语表（[11] DBDD 适用）

> 术语依据 GJB 438C-2021 及 [11] 模板正文用法整理。全文术语必须与本表保持一致；首次出现时用"中文全称（英文缩写）"格式。

## 配置管理与标识

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 计算机软件配置项 | CSCI（Computer Software Configuration Item） | 软件配置项，需求、设计、测试文档的基本对象。数据库通常随所属 CSCI 统一管理，1.1 节标识。 |
| 计算机软件部件 | CSC（Computer Software Component） | CSCI 设计中的元素：类、对象、模块、函数、例程或数据库；数据库本身可作为 CSC 出现在概要设计的部件划分中。 |
| 计算机软件单元 | CSU（Computer Software Unit） | CSCI 设计中可单独测试的最小软件元素；本文档第 5 章"用于数据库访问或操纵的软件单元"的追踪对象。 |
| 项目唯一的标识符 | — | 数据元素、数据元素集合、接口、软件单元等的唯一编号，用于全项目追踪。第 4、5 章每个对象都必须给出。 |
| 基线 | Baseline | 经正式评审确认的文档/产品版本，后续更改受配置管理控制。 |
| 文档标识号 | — | 格式示例 `TN/x-DO-DS-V{N.xx}`，见 1.1 节。 |

## 文档类型

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 数据库设计说明 | DBDD（Data Base Design Description） | [11] 本文档，描述数据库级设计决策、数据库详细设计和数据库访问/操纵软件单元设计。 |
| 软件需求规格说明 | SRS（Software Requirements Specification） | 数据库设计决策的理由应能追溯至 SRS 的需求。 |
| 软件概要设计说明 | SDD（Software Design Description） | 软件单元概要设计信息的出处，第 5 章可直接引用而不重复。 |
| 接口设计说明 | IDD（Interface Design Description） | 接口设计信息可引用 IDD 代替详述，第 3、5 章注明。 |
| 软件开发计划 | SDP（Software Development Plan） | 项目计划类文档，引用文档章可列出。 |

## 数据库设计相关

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 数据库管理系统 | DBMS（Data Base Management System） | 建立、使用和维护数据库的系统软件；第 3 章设计决策的选型对象。 |
| 数据元素 | — | 在指定设计级别上不具有结构的任何关系、属性、字段、单元（cell）、数据元素等，第 4 章 a）条描述其特征。 |
| 数据元素集合 | — | 在一指定设计级别上具有特定结构（数据元素的编号、次序、分组）的任何实体、关系、模式、字段、表、数组等，第 4 章 b）条描述其特征。 |
| 设计级别 | — | 数据库设计的层次，如概念设计、内部设计、逻辑设计、物理设计；第 4 章每个级别一个子条。 |
| 主键 | Primary Key | 唯一标识表中每条记录的数据元素或数据元素组合。 |
| 外键 | Foreign Key | 引用另一张表主键的数据元素，用于建立表之间的关联。 |
| 索引 | Index | 为提高数据检索速度而在表字段上建立的数据结构，第 3 章排序/索引设计决策涉及。 |
| 事务 | Transaction | 作为单个逻辑工作单元执行的一系列数据库操作，具有原子性、一致性、隔离性和持久性。 |
| 备份与恢复 | Backup & Recovery | 数据库数据与处理的分布策略、备份恢复过程中允许的动作，第 3 章设计决策涉及。 |

## 需求与追踪相关

| 术语 | 含义与使用场景 |
|------|----------------|
| 双向追踪 | 正向（数据库/软件单元→所处理的需求）与逆向（需求→数据库/软件单元）追踪，本文档第 6 章。 |
| 需方 / 开发方 / 保障机构 | 项目的三类相关方：需求提出方、软件开发方、维护保障组织，1.2 节标识。 |
| 运行现场 | 数据库部署使用的地点/环境，区分当前和计划的，1.2 节标识。 |
| 系统需求 / 软件需求 | 数据库设计决策与追踪的来源，引用时写明文档名和章节号。 |

## 通用软件术语（非军用专属，按源码实际出现选用）

> 纯软件、信息化项目正文中高频出现的通用术语。首次出现写"中文全称（英文缩写）"，此后用缩写；源码中未出现的不得收录。

| 术语 | 英文/缩写 | 规范写法与使用场景 |
|------|-----------|----------------|
| 结构化查询语言 | SQL（Structured Query Language） | 数据库访问语言；第 3、5 章描述数据访问方式时使用。 |
| 应用程序编程接口 | API（Application Programming Interface） | 对外接口的统称；数据库访问服务单元向上提供的操作接口。 |
| JavaScript 对象表示法 | JSON（JavaScript Object Notation） | 数据交换格式；接口数据元素、消息体的默认格式。 |
| 超文本传输协议 | HTTP（Hypertext Transfer Protocol） | 接口通信协议；数据库访问服务对外为 HTTP 接口时注明。 |
| 软件配置管理 | SCM（Software Configuration Management） | 基线、变更控制相关活动。 |

## 术语裁剪指引

- 只收录正文实际出现的术语（与第 7 章 `generation_prompt` 的要求一致）；「通用软件术语」一表按源码实际出现选用，不得为凑数整表照搬。
- 无硬件配置项（HWCI）的纯软件项目：正文不涉及硬件时，术语表不收 HWCI、物理兼容性等硬件/机电相关术语；**DBDD、DBMS、数据元素、数据元素集合必须保留**。
- 通用术语与 GJB 术语定义冲突时，以本表 GJB 定义为准，正文避免混用。
