# 军用软件文档常用术语表（[01] 软件总体技术方案适用）

> 术语依据 GJB 438C-2021 及 [01] 模板正文用法整理。全文术语必须与本表保持一致；首次出现时用"中文全称（英文缩写）"格式。

## 配置管理与标识

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 计算机软件配置项 | CSCI（Computer Software Configuration Item） | 软件配置项，1.2 节说明软件配置项划分与最终形态时使用；本文档中软件一般按一个 CSCI 管理。 |
| 硬件配置项 | HWCI（Hardware Configuration Item） | 与 CSCI 对应的硬件配置项；系统配置方案章涉及硬件配置时提及。 |
| 计算机软件部件 | CSC（Computer Software Component） | CSCI 设计中的元素：类、对象、模块、函数、例程或数据库。 |
| 计算机软件单元 | CSU（Computer Software Unit） | CSCI 设计中可单独测试的最小软件元素。 |
| 基线 | Baseline | 经正式评审确认的文档/产品版本，后续更改受配置管理控制。 |
| 文档标识号 | — | 格式示例 `TN/x-DO-DS-V{N.xx}`，见 1.1 节；本文档示例为 `XT-OTP-V1.0` 类编号。 |
| 研制状态 | — | 软件所处的研制阶段（论证、方案、工程研制、定型等），1.2 节说明。 |

## 文档类型

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 软件总体技术方案 | OTP（Overall Technical Plan） | [01] 本文档，论证与方案阶段编制，描述系统总体方案、模型设计、资源配置、接口配置、组织机构、关键技术、实施路线与经费概算。 |
| 软件开发计划 | SDP（Software Development Plan） | 后续详细计划文档，本文档实施计划章可引用其要点。 |
| 软件需求规格说明 | SRS（Software Requirements Specification） | 下游需求文档，方案中的能力划分是其输入。 |
| 软件概要设计说明 | SDD（Software Design Description） | 下游设计文档，方案中的模型设计是其输入。 |
| 接口需求规格说明 | RS（Interface Requirements Specification） | 接口需求可引用它代替详述，接口配置方案章注明。 |
| 软件研制任务书 | — | 研制依据文件，经费与指标的来源。 |

## 方案相关

| 术语 | 含义与使用场景 |
|------|----------------|
| 总体结构 / 体系结构 | 系统的组成框架与层次划分，总体方案与结构章描述。 |
| 应用系统结构 / 支撑系统结构 | 总体结构的两个侧面：直接承载业务应用的软件结构与起支撑作用的公共/基础软件结构。 |
| 信息分类编码体系 | 对系统所处理信息按类别统一编码的规则体系（可选条）。 |
| 结构模型 / 动态模型 / 功能模型 | 模型设计的三类视图：静态结构分解（功能分解树、构件图）、运行时行为（事件流、事件跟踪）、数据与加工（数据流、功能调用）。 |
| 关键技术 | 对实现系统指标起决定性作用、需专项攻关的技术，关键技术章描述其提出依据、一般说明与实现方案。 |
| 技术路线 | 实现方案的总体途径与方法选择，实施章描述。 |
| 需方 / 开发方 / 保障机构 | 项目的三类相关方：需求提出方、软件开发方、维护保障组织，1.2 节标识。 |
| 运行现场 | 软件部署使用的地点/环境，区分当前和计划的。 |

## 通用软件术语（非军用专属，按源码实际出现选用）

> 纯软件、信息化项目正文中高频出现的通用术语。首次出现写"中文全称（英文缩写）"，此后用缩写；源码中未出现的不得收录。

| 术语 | 英文/缩写 | 规范写法与使用场景 |
|------|-----------|----------------|
| 表述性状态转移 | REST（Representational State Transfer） | HTTP 资源接口风格；写接口类型时使用，如"REST 接口"。 |
| 远程过程调用 | RPC（Remote Process Call） | JSON-RPC 等远程调用协议的上位概念。 |
| JavaScript 对象表示法 | JSON（JavaScript Object Notation） | 数据交换格式；接口数据元素、消息体的默认格式。 |
| 超文本传输协议 | HTTP（Hypertext Transfer Protocol） | 接口通信协议；注明方法（GET/POST）、状态码。 |
| 应用程序编程接口 | API（Application Programming Interface） | 对外接口的统称。 |
| Java 开发工具包 | JDK（Java Development Kit） | 运行与构建环境需求。 |
| 软件配置管理 | SCM（Software Configuration Management） | 基线、变更控制相关活动。 |

## 术语裁剪指引

- 只收录正文实际出现的术语（与第 1 章 `generation_prompt` 的要求一致）；「通用软件术语」一表按源码实际出现选用，不得为凑数整表照搬。
- 本文档为方案类文档，不直接规定合格性方法与合格性级别（那是 SRS 第 4 章的内容），术语表不收此类条目。
- 无硬件配置项（HWCI）的纯软件项目：正文不涉及硬件时，术语表不收 HWCI 等硬件/机电相关术语；CSC/CSU 若正文未用作部件/单元划分也可不收，但 **CSCI 与本文档类型（OTP）必须保留**。
- 通用术语与 GJB 术语定义冲突时（如"软件单元"在通用语境与 CSU 的定义不同），以本表 GJB 定义为准，正文避免混用。
