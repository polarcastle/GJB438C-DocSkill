# 军用软件测评文档常用术语表（[18] 软件测评大纲适用）

> 术语依据 GJB 438C-2021 及 [08]/[10]/[18] 模板正文用法整理。全文术语必须与本表保持一致；首次出现时用"中文全称（英文缩写）"格式。

## 配置管理与标识

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 计算机软件配置项 | CSCI（Computer Software Configuration Item） | 软件配置项，本次测评的被测对象。 |
| 硬件配置项 | HWCI（Hardware Configuration Item） | 与 CSCI 对应的硬件配置项；测评环境的硬件组成涉及。 |
| 被测软件 | — | 本次测评的对象软件，即 config.json 中 project.name 所指软件。 |
| 项目唯一的标识符 | — | 测试项、接口、问题单等的唯一编号；4.3 节每个测试项定义都必须给出（如 XT_FUT-01）。 |
| 基线 | Baseline | 经正式评审确认的配置项版本，后续更改受配置管理控制；7.3.1 配置基线计划的对象。 |
| 配置项 | CI（Configuration Item） | 配置管理控制的最小单元（文档、源代码、可执行程序、测试工具等）。 |
| 文档标识号 | — | 格式示例 `TN/x-DO-DS-V{N.xx}`，见 1.1 节。 |

## 测评活动术语

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 文档审查 | DI（Document Inspection） | 对研制文档的齐套性、一致性、可测试性进行静态审查；4.3.1 节测试类别，标识前缀 XX_DOI。 |
| 功能测试 | FT（Function Test） | 验证软件功能与需求的一致性；4.3.2 节测试类别，标识前缀 XXX_FUT。 |
| 性能测试 | PT（Performance Test） | 测量响应时间、吞吐率、资源占用等量化指标；4.3.3 节测试类别，标识前缀 XXX_PET。 |
| 接口测试 | IOT（Interface Test） | 验证接口协议、数据格式、时序与容错能力；4.3.4 节用户自定义测试类别。 |
| 测试项 | Test Item | 测试的最小定义单元，每个测试项有唯一标识、测试内容、充分性要求和终止要求。 |
| 测试用例 | Test Case | 为验证某测试项而设计的输入、步骤与预期结果集合。 |
| 测试充分性 | Test Adequacy | 测试执行到什么程度可判定该测试项完成（如用例执行 100%、覆盖全部等价类）。 |
| 测试终止要求 | Test Stop Criteria | 单测试项中止条件（如发生 1 个一级问题即终止该项）。 |
| 回归测试 | Regression Test | 问题修改后重新执行相关测试项，验证修改未引入新问题。 |
| 软件问题 | Software Problem | 测评中发现的软件缺陷，按类型（功能/性能/接口/安全性/文档）与严重性等级（一级～四级）分类；4.5 节。 |
| 战技指标 | — | 研制总要求中规定的战术技术指标，须逐条追踪到测试项；4.4 节追踪表。 |

## 文档类型

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 软件测评大纲 | STO（Software Test Outline） | [18] 本文档，规定测评内容、方法、环境与安排。 |
| 软件需求规格说明 | SRS（Software Requirements Specification） | [08] 需求文档，测试项章节号追踪的对象之一。 |
| 软件概要设计说明 | SDD（Software Design Description） | [10] 概要设计文档，文档审查的对象之一。 |
| 软件研制总要求 | — | 任务来源文件，战技指标与功能指标的出处，测试项章节号追踪的对象之一。 |
| 软件测试说明 | STD（Software Test Description） | 测评大纲之后编制的测试执行层文档（引用时注明）。 |
| 软件测试报告 | STR（Software Test Report） | 测评完成后编制的总结性文档（引用时注明）。 |

## 通用软件术语（非军用专属，按源码实际出现选用）

> 纯软件、信息化项目正文中高频出现的通用术语。首次出现写"中文全称（英文缩写）"，此后用缩写；源码中未出现的不得收录。

| 术语 | 英文/缩写 | 规范写法与使用场景 |
|------|-----------|----------------|
| 应用程序编程接口 | API（Application Programming Interface） | 被测软件对外接口的统称。 |
| 集成开发环境 | IDE（Integrated Development Environment） | 测评环境表中开发类软件的描述。 |
| 中央处理器 | CPU（Central Processing Unit） | 硬件环境配置与性能指标的描述。 |
| 随机存取存储器 | RAM（Random Access Memory） | 硬件环境配置与资源占用指标的描述。 |
| 只读存储器 | ROM（Read Only Memory） | 嵌入式目标机环境描述。 |
| 软件配置管理 | SCM（Software Configuration Management） | 第 7 章配置管理活动。 |
| 软件质量保证 | SQA（Software Quality Assurance） | 第 8 章质量保证活动。 |

## 术语裁剪指引

- 模板无硬件配置项（HWCI）的纯软件项目：正文不涉及硬件时，术语表不收 HWCI 等硬件专属术语；但 **CSCI、被测软件、基线、配置项与本文档类型（STO）必须保留**。
- 裁剪原则：只收录正文实际出现的术语（与 `generation_prompt` 的要求一致）；「通用软件术语」一表按源码实际出现选用，不得为凑数整表照搬。
- 通用术语与 GJB 术语定义冲突时，以本表 GJB 定义为准，正文避免混用。
