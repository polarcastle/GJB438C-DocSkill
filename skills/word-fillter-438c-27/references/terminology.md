# 军用软件文档常用术语表（[27] 软件标准化工作报告适用）

> 术语依据 GJB 438C-2021 及 [08]/[10]/[27] 模板正文用法整理。全文术语必须与本表保持一致；首次出现时用"中文全称（英文缩写）"格式。

## 配置管理与标识

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 计算机软件配置项 | CSCI（Computer Software Configuration Item） | 软件配置项，软件文档与研制过程管理的基本对象。 |
| 硬件配置项 | HWCI（Hardware Configuration Item） | 与 CSCI 对应的硬件配置项；纯软件项目正文未涉及时不收录。 |
| 项目唯一的标识符 | — | 接口、需求、文档等的唯一编号，用于全项目追踪。 |
| 基线 | Baseline | 经正式评审确认的文档/产品版本，后续更改受配置管理控制。本文档所述各阶段文档均应在通过评审后建立基线。 |
| 文档标识号 | — | 格式示例 `TN/x-DO-DS-V{N.xx}`，见 1.1 节。 |
| 配置管理 | SCM（Software Configuration Management） | 源代码、文档与数据项的受控管理，包括基线管理、变更控制，见 6.1 节。 |
| 软件质量保证 | SQA（Software Quality Assurance） | 软件研制过程的质量保证活动，相关计划见引用文档。 |

## 文档类型

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 软件标准化工作报告 | SWR（Software Standardization Work Report） | [27] 本文档，总结软件研制过程的标准化工作、成果与执行情况。 |
| 软件标准化大纲 | — | 课题标准化工作的顶层依据文件，规定标准化要求、组织与审查安排；本文档多处引用。 |
| 软件需求规格说明 | SRS（Software Requirements Specification） | [08]，研制阶段文档之一，标准化审查对象。 |
| 软件概要设计说明 | SDD（Software Design Description） | [10]，研制阶段文档之一，标准化审查对象。 |
| 软件开发计划 | SDP（Software Development Plan） | 开发过程、进度与资源管理的计划文件，见 6.1 节。 |
| 软件研制任务书 | — | 研制任务来源文件，标准化分析的输入之一，见 5.1 节。 |

## 标准化专业术语

| 术语 | 含义与使用场景 |
|------|----------------|
| 标准化 | 在既定范围内获得最佳秩序，对实际或潜在问题制定共同使用和重复使用的条款的活动。本文档工作的总主题。 |
| 标准化大纲 | 规定课题标准化工作目标、要求、组织职责与实施安排的文件，是各阶段标准化工作的依据。 |
| 标准体系表 | 一定范围内标准按其内在联系排列起来的图表，是确定适用标准清单的基础（5.X 节"标准化确定"）。 |
| 标准适用性分析 | 对照研制任务与标准条款，识别本课题应执行的标准化要求的活动（5.X 节"标准化分析"）。 |
| 标准化保证 | 在研制活动中落实已确定的标准化要求、使工作产品与标准保持一致的活动（5.X 节）。 |
| 标准化审查 | 对研制过程及产品是否符合标准要求进行的检查与评定，分阶段实施并留有记录（5.X 节"标准化审查"、6.4 节）。 |
| 标审 | 文档审查流程中的一个审签环节（校对、审核、标审、审定、批准），见 6.4 节。 |
| 归零 | 对审查或测试发现的问题完成原因分析、纠正措施与验证关闭的管理活动，见第 5、7 章。 |

## 项目相关方

| 术语 | 含义与使用场景 |
|------|----------------|
| 需方 | 软件需求的提出方，1.2 节标识。 |
| 开发方 | 承担软件开发任务的单位内部部门，1.2、第 8 章使用。 |
| 用户 | 软件的使用者与操作维护人员，1.2 节标识。 |
| 保障机构 | 负责软件维护保障的组织，1.2 节标识。 |
| 运行现场 | 软件部署使用的地点/环境，区分当前和计划的，1.2 节。 |

## 通用软件术语（非军用专属，按项目实际出现选用）

> 首次出现写"中文全称（英文缩写）"，此后用缩写；项目中未出现的不得收录。

| 术语 | 英文/缩写 | 规范写法与使用场景 |
|------|-----------|----------------|
| 应用程序编程接口 | API（Application Programming Interface） | 对外接口的统称，接口约定相关章节使用。 |
| JavaScript 对象表示法 | JSON（JSON Object Notation） | 数据交换格式；接口数据元素描述使用。 |
| 超文本传输协议 | HTTP（Hypertext Transfer Protocol） | 接口通信协议；注明方法与状态码。 |

## 术语裁剪指引

- 只收录正文实际出现的术语（与第 9 章 `generation_prompt` 的要求一致）；「通用软件术语」一表按项目实际出现选用，不得为凑数整表照搬。
- 纯软件项目（无 HWCI、无硬件接口约定）正文不涉及硬件时，术语表不收 HWCI 等硬件相关术语。
- 通用术语与 GJB 术语定义冲突时，以本表 GJB 定义为准，正文避免混用。
