# 军用软件文档常用术语表（[25] SPS 适用）

> 术语依据 GJB 438C-2021 及 [25] 模板正文用法整理。全文术语必须与本表保持一致；首次出现时用"中文全称（英文缩写）"格式。

## 配置管理与标识

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 计算机软件配置项 | CSCI（Computer Software Configuration Item） | 软件配置项，本文档描述其软件产品包的构成与有效拷贝判据。全文以 CSCI 指代被交付软件。 |
| 计算机软件单元 | CSU（Computer Software Unit） | CSCI 设计中可单独测试的最小软件元素；SPS 第 6 章建立源文件与软件单元的双向追踪。 |
| 基线 | Baseline | 经正式评审确认的文档/产品版本，后续更改受配置管理控制；修改规程（5.3）要求修改并入产品基线。 |
| 项目唯一的标识符 | — | 文档编号、接口编号等的唯一编号；1.1 节标识号格式示例 `TN/x-DO-DS-V{N.xx}`。 |
| 有效拷贝 | — | 与 3.1 条、3.2 条引用文件精确匹配的软件实体，第 4 章给出证明方法。 |
| 校验和 | Checksum | 通过对文件内容计算得到的完整性比对数值（如 CRC32、MD5），第 4 章合格性证明手段。 |

## 文档类型

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 软件产品规格说明 | SPS（Software Product Specification） | [25] 本文档，描述以电子媒体交付的软件产品构成、合格性证明方法与软件支持信息。 |
| 软件设计说明 | SDD（Software Design Description） | "已建成"CSCI 的设计信息载体，5.1 条引用。 |
| 接口设计说明 | IDD（Interface Design Description） | 接口设计信息等价文档，5.1 条注明。 |
| 数据库设计说明 | DBDD（Data Base Design Description） | 数据库呈现设计等价文档；不使用数据库时如实说明无 DBDD 等价文档。 |
| 软件开发计划 | SDP（Software Development Plan） | 资源使用测量策划的出处，5.4 条引用。 |
| 软件配置管理计划 | SCMP（Software Configuration Management Plan） | 修改规程与配置管理活动的依据，5.3 条引用。 |
| 软件研制任务书 | — | 软件研制任务来源文件，1.2 节相关方与研制依据。 |

## 交付与支持（SPS 专用）

| 术语 | 含义与使用场景 |
|------|----------------|
| 可执行软件 | CSCI 在目标计算机上安装和运行所需的可执行程序、批处理文件、命令文件、数据文件等，3.1 条。 |
| 源文件 | 重新生成 CSCI 可执行软件所需的源代码及配套文件，3.2 条。 |
| 包装需求 | CSCI 拷贝的包装、标记和储运要求，3.3 条。 |
| 编译/建立规程 | 从源文件创建可执行文件并加载到分布媒体的完整规程，5.2 条。 |
| 修改规程 | 修改 CSCI 应遵循的规程，5.3 条。 |
| 计算机硬件资源使用 | "已建成"CSCI 对处理器、内存、I/O、辅存、通信资源的实际使用数据，5.4 条。 |
| 测量级别 | 资源使用数据估计或测量的级别：软件单元级、CSCI 级或可执行程序级，5.4 e）。 |

## 纯软件项目（无 HWCI）的术语裁剪指引

- 无硬件配置项（HWCI）的纯软件项目：正文不涉及硬件时，术语表不收 HWCI 等硬件/机电相关术语；**CSCI、CSU、SPS 必须保留**。
- 裁剪原则：只收录正文实际出现的术语（与第 7 章 `generation_prompt` 的要求一致）；「通用软件术语」按项目实际出现选用，不得为凑数照搬。
- 通用术语与 GJB 术语定义冲突时，以本表 GJB 定义为准，正文避免混用。
