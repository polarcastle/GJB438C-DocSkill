# 军用软件文档常用术语表（[15] STP 适用）

> 术语依据 GJB 438C-2021 及 [15] 模板正文用法整理。全文术语必须与本表保持一致；首次出现时用"中文全称（英文缩写）"格式。

## 配置管理与标识

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 计算机软件配置项 | CSCI（Computer Software Configuration Item） | 软件配置项，本文档测试活动的基本对象；测试级、需求追踪均以 CSCI 为单位表述。 |
| 项目唯一的标识符 | — | 测试项、测试用例、需求等的唯一编号，用于全项目追踪。5.2.X.Y 要求每个测试项有项目唯一的标识符。 |
| 基线 | Baseline | 经正式评审确认的文档/产品版本，后续更改受配置管理控制；测试环境的变更同样受控。 |
| 文档标识号 | — | 格式示例 `TN/x-DO-DS-V{N.xx}`，见 1.1 节。 |

## 文档类型

| 术语 | 英文/缩写 | 含义与使用场景 |
|------|-----------|----------------|
| 软件测试计划 | STP（Software Test Plan） | [15] 本文档，规划测试环境、测试标识、进度与终止条件。 |
| 软件测试说明 | STD（Software Test Description） | 描述各测试项执行细节（用例、规程），STP 1.4 引用。 |
| 软件测试报告 | STR（Software Test Report） | 测试完成后对结果与评价的报告，STP 第 6/7 章引用。 |
| 软件需求规格说明 | SRS（Software Requirements Specification） | 被测需求的出处，测试依据与追踪的源头。 |
| 接口需求规格说明 | IRS（Interface Requirements Specification） | 接口需求的出处，第 8 章追踪覆盖范围注明。 |
| 系统/子系统规格说明 | SSS（System/Subsystem Specification） | 系统级需求的出处，系统级测试时第 8 章注明。 |
| 软件开发计划 | SDP（Software Development Plan） | 测试进度与资源安排的协调来源，STP 1.4 引用。 |
| 软件研制任务书 | — | 测试任务与验收要求的任务来源文件。 |

## 测试专用术语

| 术语 | 含义与使用场景 |
|------|----------------|
| 测试级 | 测试的级别，如 CSCI 级、系统级，5.1.1 定义。 |
| 测试类别 | 测试的类型，如功能测试、性能测试、容量测试，5.1.2 定义。 |
| 测试程度 | 测试覆盖的量化表示（占已妥善定义总量的百分比或抽样方法），5.1.3 陈述。 |
| 回归测试 | 软件变更后重新执行受影响用例的测试，5.1.3、第 6 章注明途径。 |
| 合格性方法 | 需求规格说明为每个需求规定的验证方法（A-演示、B-测试、C-分析、D-检查、E-特殊方法），5.2.X.Y d）引用 SRS 的规定。 |
| 测试现场 | 执行测试的地点及其软硬件环境，第 4 章按现场分条描述。 |
| 再测试 | 缺陷修复或变更后，对原不通过用例的重复执行，第 6 章计划注明。 |
| 评价准则 | 判定被测软件满足需求程度的准则，第 7 章定义。 |

## 通用软件术语（非军用专属，按项目实际出现选用）

> 纯软件、信息化项目正文中高频出现的通用术语。首次出现写"中文全称（英文缩写）"，此后用缩写；项目中未出现的不得收录。

| 术语 | 英文/缩写 | 规范写法与使用场景 |
|------|-----------|----------------|
| JavaScript 对象表示法 | JSON（JavaScript Object Notation） | 测试数据文件格式；记录输入输出数据时注明。 |
| 超文本传输协议 | HTTP（Hypertext Transfer Protocol） | 被测接口通信协议；接口测试时注明方法与状态码。 |
| 应用程序编程接口 | API（Application Programming Interface） | 被测对外接口的统称。 |
| 软件配置管理 | SCM（Software Configuration Management） | 测试环境、测试数据与缺陷的变更控制。 |

## 纯软件项目（无 HWCI）的术语裁剪指引

- 无硬件配置项（HWCI）的纯软件项目：正文不涉及硬件时，术语表不收 HWCI、固件相关术语；CSCI 保留，作为测试级与追踪的基本对象。
- 裁剪原则：只收录正文实际出现的术语；「通用软件术语」一表按项目实际出现选用，不得为凑数整表照搬。
- 通用术语与 GJB 术语定义冲突时，以本表 GJB 定义为准，正文避免混用。
